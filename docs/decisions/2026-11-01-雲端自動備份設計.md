# 雲端自動備份設計（2026-11-01，設計員出稿，待使用者確認）

> 規範見 [DESIGN.md](../design/DESIGN.md) 5.28；模擬頁 `docs/design/mockups/{手機,平板,桌機}-雲端自動備份.html`；產生程式 `docs/design/build/batch81.mjs`。**沒有改 `src/`、沒有發布。**

## 背景

google-ui 的 PR #52（`src/app/cloud.ts`）讓登入 Google 後，每次設定更新都自動把「問卷小幫手設定.sfh」（含學生名單）存到老師自己的雲端硬碟（`drive.file`），目前只有 toast，沒有說明卡與開關。隱私考量與硬規則 11 要求先有設計並讓老師明確同意；調度員暫不合併 #52，等本稿。

## 結論

| 項目 | 決定 | 原因／被否決的選項 |
|---|---|---|
| 預設值 | **開關預設關**，需明確同意 | 檔案含學生名單、放第三方；預設關只多一次點擊。被否決：預設開（老師可能不知道名單被複製）。登入 Google（為了讀試算表）不等於同意備份 |
| 同意在哪裡做 | 兩處同一個設定：登入前說明卡的開關（Y1）、設定頁開關（Y3；已登入時先跳 Y4 確認卡）。偏好存瀏覽器（介面偏好），被清掉回到預設關 | 只放設定頁：手機老師登入當下看不到說明；只放登入卡：已登入的人要再找入口 |
| 說明文字 | 四句：存什麼（含學生名單、不含作答結果）、只存這一個檔、我們看不到、學校管理員可能看得到 | 「學校管理員」一句是設計員補的，見下〈待使用者決定〉 |
| 關閉後 | 不再存；雲端那份留著、程式不刪；資料夾不受影響；可選「同時中斷 Google 連線」（預設不勾） | 自動刪雲端檔：會刪到老師想留的備份，且需要更大的權限 |
| 這次沒登入 | 開關仍開、顯示警示「沒有備份」＋登入鈕；不自動彈視窗 | 權杖只在記憶體；自動彈視窗沒有點擊會被擋 |
| toast | 成功只出現第一次、5 秒；失敗不自動消失、可有動作鈕；同種失敗同一次開啟只跳一次；限流與空間滿分開寫 | 每次成功都跳：改設定時太吵 |
| 與資料夾 | 資料夾＝正本先寫，雲端＝選用備份後寫、同名覆蓋、只寫不讀；兩台電腦同帳號後存蓋掉先存 | 雲端讀回來自動合併：超出範圍，且名單衝突難處理 |
| 設定頁不顯示信箱 | 只用 `drive.file`，拿不到信箱，也不去查（取消帳號限制後 `about.get` 已不做） | 舊稿 10d「已連線設定」寫「顯示連線的帳號」，與現況不符，待後續順手對齊 |

## 我替使用者決定的事（可改回）

1. 預設關（上表）。
2. 登入前卡的選帳號示意圖在手機與平板收成一列（點開才展開）以騰出空間；桌機照舊。
3. 加了「學校管理員可能看得到」這句與「請用個人帳號」的建議。
4. 失敗 toast 不自動消失；同種失敗只跳一次。
5. 新增 Y3b（這次沒登入）、Y3c（備份暫停）、Y5（關閉確認）、Y8（先後順序）四種畫面，Y4 是開啟確認卡。

## 需要使用者決定

1. 開關預設關：同意嗎？（建議：同意；若要預設開，Y1 的開關要改成預設打開，且說明卡仍須在登入前出現。）
2. 「學校管理員可能看得到這個檔」那句要不要留？（建議：留，因為取消帳號限制後學校帳號也能登入。）
3. 登入前卡是否同時放開關？（建議：放；否則手機老師要登入後再去設定頁找。）

## 給實作（google-ui）的注意

- `cloud.ts` 要先看開關偏好；`announced` 旗標沿用；失敗要加「同種只跳一次」。
- `src/google/quota.ts` 的 `quota` 把限流（429、rateLimit）與雲端空間滿（`storageQuotaExceeded`）混在一起；`failureMessage` 是給讀取用的（「改用 Excel 檔」），存檔要另寫，文案見 DESIGN.md 5.28 表格。
- toast 要支援失敗樣式（圖示、`role="alert"`、動作鈕、不自動消失）；現有 `.toast` 只有文字。

## 沒驗到

真實 Google 存檔與錯誤碼（沒登入實測）；各校管理員權限；淺色與實機（只用 Edge 無頭看過三個裝置的深色版面）。畫面一律標「待核對」：雲端硬碟顯示位置名稱、「移到垃圾桶」字樣、系統選檔視窗名稱、「使用其他帳戶」。
