# 進階統計定義（核心純函式）

日期：2026-11-01。分支 adv-stats。程式在 `src/core`（`feedback.ts`、`mean.ts`、`scale.ts`、`advanced.ts`、`trend.ts`、`anonymize.ts`），測試資料全部虛構。

## 定義與預設（藍圖「報告回饋」「歷次趨勢」「去識別化」）

| 項目 | 定義 | 未定案處（我的建議） |
|---|---|---|
| 加權 | 沿用既有 `effectiveWeights`，預設等重（R-014） | — |
| 去極端值 | `summarizeFeedback(..., { trim: k })`：每題各去掉最高、最低 k 個再平均；該題有效筆數 ≤ 2k 時不去除（`trimmed=false`），避免削光資料 | k 預設 0（不去除），建議 UI 提供 0／1。藍圖寫「去掉最高最低分」＝k=1 |
| 反向題 | `FeedbackItem.reversed`：先驗範圍，再換成 min+max−分數；自評同樣換算 | — |
| 量表標籤 | `scale.ts`：分數↔標籤、讀「非常同意」「5 非常同意」、平均轉最近標籤（平手取高） | 預設範本只給五點同意度 |
| 自評對他評 | 每題與總分的 自評−他評；差絕對值超過 1 分才標偏高／偏低；總分只比兩邊都有分數的題 | 門檻 1 分可由 UI 調 |
| 小組互評 | 只計同組組員互評（不含自評、他組評分者）；每人 received＝同組給他的分數平均；share＝占全組 received 總和；index＝received÷全組平均；組別由呼叫端提供 `groupOf` | 不修正「評分者偏鬆」；若老師要，下一版可加每位評分者標準化 |
| 歷次趨勢 | `compareTrend`：班均、各題（以題目名稱比對，id 不同也接）、每人總分與名次；差與前一個有值的點比；±0.05 內視為持平 | 題目改名會被當成新題 |
| 去識別化 | `pseudonymize`：班級＋姓名去重編 S01…，可帶種子洗牌；`deidentifySummary` 只留代號並遮蔽留言內已知姓名 | 對照表只給老師，輸出時不可一起帶出；名單外姓名無法自動遮蔽 |
| 三版本 | `buildView`：教師版完整；學生版匿名彙整（無名次、無來源編號、姓名換「某同學」）；家長版精簡（總分、班均、最多 2 則留言） | 兩版預設不含名次，`showRank` 可開 |

## 使用者裁示（2026-11-01，問題卡）

- 小組互評先不修正評分者偏鬆／偏嚴；之後有需要再加每位評分者標準化。
- 去識別化對名單外的人名無法自動遮蔽：輸出學生版／家長版前，介面提醒老師並要求預覽（UI 待辦，併入 v0.1 後半或編輯器）。
