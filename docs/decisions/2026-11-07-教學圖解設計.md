## 三、設計重點（細節見 DESIGN.md 5.32）

- **一步＝一張圖＋一兩句短字**；圖在上、字在下。步驟格欄數跟卡片寬度自動排（手機 1、平板 2、桌機前置 3），不寫三套版面。
- **三種視窗**：本程式（淡藍標題列＋「本程式」）／外部已核對（實線、寫服務名稱、不畫 Logo）／外部未核對（虛線、灰條、「待核對」）。
- **要按的**：強調色外框＋游標；**標出但不用按**：虛線外框。可用不可用一律寫字（✓ 能讀／✕ 讀不了），不只靠顏色。
- 每張圖下固定「自畫示意，不是截圖」。
- 全部 HTML＋內嵌 SVG、走 tokens：深色自動成立，沒有點陣圖。

3. **做法二的「適合」拿掉「學校帳號被擋」**，改成「手機、平板、Safari、Firefox，或不想登入的人。」（開工令第 4 點）。做法一「遇到問題」第 2 種拿掉「學校管理員限制第三方應用程式」，改成「還是不行就改用做法二」。選帳號示意圖拿掉「個人帳號／學校帳號」的分類標示與「個人帳號、學校帳號都能用」。

## 五、被否決的方案與原因

| 方案 | 否決原因 |
|---|---|
| 用 Google 畫面截圖加框 | 使用者禁止（著作權、Google 改版就過期、截圖含帳號頭像）。 |
| 整張圖用一個大 SVG（含文字） | SVG 文字不會換行，手機縮小後字太小；深色要另做一套。改用 HTML 方塊＋少量 SVG。 |
| 圖上用數字標註（①②）表示按的順序 | 會和步驟編號混淆；一步通常只按一兩個，用游標＋箭頭就夠。 |
| 左右箭頭表示先後 | 手機與桌機並排的做法卡都很窄，左右排會擠；統一上下排。 |
| 平板與桌機圖在左、字在右 | 平板內容欄約 500，左右分會讓圖與字都太窄；改成步驟格兩欄。 |
| 每一步都畫圖（含「開放題少而精」「之後有新回應」） | 沒有可畫的操作，為湊數畫圖只會拉長頁面。 |
| 未核對的 Google 視窗照記憶畫出字樣 | 違反硬規則 10；改成虛線框＋灰條＋「待核對」。 |
| 首頁匯出提示、登入被擋另畫新圖 | 同一個操作畫兩套會走鐘；沿用教學頁的圖。 |
