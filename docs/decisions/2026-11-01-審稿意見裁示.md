## 暫定與風險

- **硬規則 6 範圍我（Claude）曾建議只放寬名單；使用者選了「名單加審稿進度」。** 審稿進度含學生回饋內容與老師評語，隱私風險高於單純名單。已知後果：共用電腦可能外洩、清除瀏覽器資料就消失、需要「刪除全部」入口與清楚說明；隱私文案（R-031）要照這個範圍寫。是否要加「離開時自動清除」「存多久」等限制，**未討論，待設計時提案**。
- 硬規則 6 修改後，下列檔案還有舊寫法，**尚未同步**（見 todo）：`CONTRIBUTING.md`、`.github/pull_request_template.md`、`README.md`、`SECURITY.md`、`docs/feature-blueprint.md`、`docs/design/DESIGN.md`、`docs/decisions/2026-10-30-技術選型與發布規則.md`、`2026-10-30-產品範圍與技術決定.md`、首頁「最近的專案」R-003 的做法（原做法 A 只記檔案位置與設定，是否擴充為存名單，施工時對齊）。
- R-005 已裁示的隱私句與 R-003「關閉頁面就清除的承諾可保留」，因本次放寬而**不再成立**，以 R-031 兩句為準。
- R-044 查證結果未出；若 Sheets API 需另開服務，要重新評估硬規則 4（API 金鑰只開 Drive 與 Picker）。

## R-044／R-027 查證結果（2026-11-01 台北時間，對照 Google 官方文件）

只讀官方頁面，**沒有實機驗證**（尚無 Cloud 專案與登入設定）。Google 文件會改版，動工前要重查。

| 問題 | 結果 | 來源 |
|---|---|---|
| `drive.file` 能否搭配 Sheets API 直讀？ | **文件上可以。** `spreadsheets.get` 與 `spreadsheets.values.get` 的授權範圍清單都含 `drive.file`（任一個即可）。`drive.file` 涵蓋使用者用 Google Picker 選給本程式的檔案，被列為非敏感範圍。 | [values.get](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/get)、[spreadsheets.get](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/get)、[Drive 授權範圍](https://developers.google.com/workspace/drive/api/guides/api-specific-auth) |
| 能讀到最新內容嗎？ | Sheets API 讀的是呼叫當下的即時內容，不是匯出的快照（我的推論，官方頁面未直接這樣寫）。 | 同上 |
| 硬規則 4（API 金鑰只開 Drive 與 Picker） | 直讀需再啟用 **Google Sheets API**，要改寫硬規則 4 與〈技術選型與發布規則〉。 | — |
| 免費配額 | Sheets API 讀取：每專案每分鐘 300 次、每使用者每分鐘 60 次。Drive API：每專案每分鐘 100 萬配額單位、每使用者 32.5 萬。 | [Sheets 限額](https://developers.google.com/workspace/sheets/api/limits)、[Drive 限額](https://developers.google.com/workspace/drive/api/guides/limits) |
| 費用 | 官方寫標準使用不另收費；**超出配額的用量「預計 2026 年稍晚」向 Cloud 帳單帳戶收費**，細節至少提前 90 天公告。超額請求目前回 429／403。 | 同上 |
| 驗證 | `drive.file` 非敏感，只需基本 OAuth 應用程式驗證（較精簡）。 | Drive 授權範圍頁 |
