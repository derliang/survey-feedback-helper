# 頁面討論裁示（2026-10-31）

> 使用者以問題卡逐批裁示 [頁面討論紀錄](../design/頁面討論紀錄.md) R-001～R-028 與 repo 維護事項，並新增 R-029。設計稿與程式尚未套用，施工清單見 [todo.md](../../todo.md)。

## 頁面修改

| 編號 | 主題 | 裁示 |
|---|---|---|
| R-001 | 示範資料 | 保留功能但移到教學頁；D12 與開啟畫面右側兩個入口都拿掉。測試用虛構資料另外保留。 |
| R-002 | Google 入口 | 本機資料夾軌併入「本機檔案」，不再是獨立入口；v0.4 登入軌保留，入口放設定頁。 |
| R-003 | 最近的專案 | 不存分析結果，採做法 A：只記檔案位置與設定，一鍵重新讀檔並重算；硬規則 6 不變。筆數與卡片版面由設計稿提案。 |
| R-004 | 首頁與步驟列 | 「增加每關度」的意思是每步的完成度（例如準備資料 2／4）。「不美觀」四項都是：留白與比例、層次不清、太像表單、顏色太素，依此出 2～3 個方案。拖放區用「把 Excel 檔拖到這裡」，不提 csv（功能仍支援）。「開啟試算表」照用，不必區分 Google 試算表。 |
| R-005 | 隱私文案 | 拆兩句，寫清雲端例外。例句：「本程式沒有伺服器，資料只在這個瀏覽器處理。檔案若放在雲端硬碟或同步資料夾，由該雲端服務處理。」因 R-003 採做法 A，「關閉頁面就清除」的承諾可保留，定稿字句於施工時確認。 |
| R-006 | 準備資料順序 | 順序固定為問卷類型 → 欄位對應 → 學生名單（選用）→ 資料檢查；前兩件完成後才解鎖，名單可跳過。 |
| R-007 | 匯出教學 | 自畫簡化 SVG 示意圖，讀不到檔案、首頁連結、教學頁共用同一組；不用 Google 截圖。 |
| R-009 | 問卷類型 | v0.1 維持三種獨立類型，新情境做成快速範本：活動滿意度、家長意見、教學回饋、學習自評、報名點名清點、班規議題票選。選課分組志願需要排序題與名額，快速範本做不到，改在 v0.1 之後做成獨立類型。 |
| R-010 | 匯出樣本 | 由 Claude 用使用者的瀏覽器建一份虛構表單並匯出，使用者負責登入；只用虛構資料。 |
| R-011 | 增減欄位 | 「增加」只指把被忽略的試算表欄位加回來（不做多欄合組與自訂用途）。「減少」是把不使用的欄收到下方，仍看得到、可找回；所有問卷類型共用。 |
| R-012 | 名單匯入 | 同一班／混班用兩個頁籤。預覽表可改座號或插入缺號，同名標示並請老師確認。名單檔有座號欄就用，沒有就自動補；姓名前的數字辨識為座號。問卷有座號欄時要核對名單，不符列請確認。混班缺班級或座號時標出該列請老師補，不補不猜。班級名稱照老師貼的不限格式，同一班手填。 |
| R-013 | 明細欄位 | 欄位固定「班級、座號、姓名」，單班時班級用淡字；D22 確認卡與「複製未填名單」都帶這三項。 |
| R-014 | 權重 | 只有量表評分項目分權重，開放題不算。除不盡時內部用等重計算，顯示到小數一位，合計顯示 100%。手動改後其他項不動，合計不是 100% 時停用下一步並指出差多少，附「恢復等重」。沒手動改過時，增刪項目自動重新平分。權重欄寫明「預設：每項等重」。 |
| R-015 | 票選名單 | 名單每列一位同學，多票可展開各份勾選，取代 D48。多票、自投、時間異常、空白票都有名單。預設沿用整類決定，可全選／全不選。D49 整類規則是預設，逐人勾選是例外，標示「X 位為手動調整」。也套用到意見調查與報告回饋的資料檢查。名單顯示投給誰，投影時隱藏。 |
| R-016 | 班均 | 寫法「班均（已計入 6 組／共 8 組）」，沒有總數時只寫已計入；有效評分就算被計入；班均包含自己這組；所有出現班均的地方都註明；資料不齊時上方提示「排名可能改變」。 |
| R-017 | 統計圖表 | 範圍是所有統計畫面。七種候選全加：圓環／圓餅、堆疊橫條、直方圖、雷達圖、散布圖、盒鬚圖、圓點圖。操作：每個畫面有「圖表」按鈕勾選清單，每張圖右上角可換圖或隱藏；不做儀表板。選擇存在設定與範本，不含資料；統計畫面選的圖是輸出文件的預設。 |
| R-018 | 審稿圖表 | 回饋單要放哪些圖，在輸出設定全班一致勾選，審稿頁可覆寫單一學生；與 R-017 合併設計。 |
| R-019 | 回饋單配色 | 單一配色，轉灰階仍有明度階梯，加標籤保底，預覽可模擬黑白；「黑白列印模式」列為後續進階。活潑靠鮮明主色、色塊與 SVG 圖示，不用 emoji、不做大幅插圖。黑白友善套用所有輸出文件，電子檔與列印用同一套彩色。 |
| R-020 | 改寫對話框 | 兩框等高、內距圓角字級一致，原文灰底並標唯讀，改寫白底；高度隨較長者並設相同最小高度。併入 R-026 的並排卡片共用規則。 |
| R-021 | 常用評語 | 內建六類預設，每類 5～8 句，由 Claude 擬稿、使用者修改後才收進設計稿；老師可新增、改寫、刪除、排序；籌碼顯示短標題可預覽整句，插在游標處並支援 {姓名}；不分年級科目；用分類頁籤加搜尋；不做分數推薦。 |
| R-022 | 存成常用評語 | 預設存整段，有選取時存選取部分；學生姓名自動換成 {姓名}，存前可看可改；先放「我的」分類；重複時提示不新增；按鈕放評語欄右下角。 |
| R-023 | 完成人數 | 直接顯示，不設開關；審稿與評語畫面統一「已完成 N／總人數 人」並加細進度軌道；有寫評語或標「跳過」就算完成。 |
| R-024 | 編輯器圖表 | 圖表種類同 R-017；選擇器改帶縮圖的清單，只顯示適用的圖。 |
| R-025 | 自訂版面 | 「版面」指整份範本。恢復預設放頂端列且二次確認，區塊與頁面設定在各自面板局部還原。第一次修改內建範本就複製成「我的範本」並命名。範本庫與編輯器都能叫出；名稱重複時提示；「已儲存在這個瀏覽器」可點，說明位置並提供備份入口。 |
| R-026 | 並排卡片 | 寫成 DESIGN.md 共用規則：等高、按鈕貼底同一水平線，套用 D7、D25、D48；兩顆按鈕保留主次樣式。受 R-002 影響，D7 是否保留於施工時依新入口確認。 |
| R-027 | 配額文案 | 查證前 D45 先收斂，不保證恢復與費用，改寫「目前無法使用 Google 連線，請改用本機檔案」。查證本身維持暫緩（使用者 2026-10-30 說先不要）。 |
| R-028 | 設定按鈕 | 平板與桌機用齒輪加「設定」文字（描邊次要按鈕、高 44px），手機只用齒輪圖示並保留無障礙標籤；與 R-004 頂端列合併設計。 |
| R-008 | 用語 | 2026-10-30 已定案：全產品一律把「猜」改為「智慧判斷」。 |
| R-029 | 預設圖表 | 圖表附一句用途說明，由老師自選；每種統計預設一張：票選長條、量表堆疊橫條、報告回饋對照條、趨勢折線、交叉熱圖。 |

## 被否決的選項

- 分析結果存進瀏覽器（要改硬規則，共用電腦有外洩風險）。
- 整個取消示範資料或 Google 登入軌。
- Google 實際截圖（改版就過時，且有商標與翻譯問題）。
- 每種情境都做成獨立問卷類型（工作量大增）。
- 手動改權重時自動平分其他項（會改掉已調好的項目）。
- 分數推薦評語（使用者選不做）。
- 儀表板畫面（使用者選勾選清單加換圖）。
- 一開始就做黑白列印模式（列為後續進階）。
