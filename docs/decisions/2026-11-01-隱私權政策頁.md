## 做法

- 靜態頁 `public/privacy.html`：Vite 會原樣複製到 `dist/` 根目錄，不經過 Preact，不影響首頁 150 KB 預算。繁體中文為正本，文末接英文版（`#english`，語言標為 `en`）。
- 沿用 `docs/design/tokens.css`：頁面把 tokens 原文內嵌（頁面要能單獨開，不依賴程式的 CSS），`scripts/privacy-page.test.mjs` 會比對內嵌內容與 tokens.css 一致，避免走鐘。深色模式跟隨系統。
- 入口：首頁頁尾與設定頁「資料去向」卡片都有「隱私權政策」連結（新分頁開啟，避免離開後遺失只存在記憶體的問卷資料；點擊區 ≥44）。字串進 `strings.ts`／`strings.en.ts`，英文覆蓋率測試涵蓋。
- Service Worker：原本所有導覽請求都回首頁，離線或已安裝 SW 時會讓 `privacy.html` 打不開；改為只有非 `.html` 的導覽才回首頁（`public/sw.js`）。`privacy.html` 會進預先快取清單。

## 需要使用者決定（已傳調度員）

1. **「Limited Use」聲明**：政策寫了「遵守 Google API 服務使用者資料政策，含限制使用規定」（Google 品牌驗證通常要求）。這是對外承諾，請使用者確認願意。
2. **聯絡方式只有 GitHub Issues**：依指示不寫個人信箱；Google 的「支援電子郵件」欄位（品牌頁已填）與此不衝突，但 Issues 是公開的，頁面已提醒不要貼個資。
3. 政策頁以**個人開發者**口吻，沒有署名或機構名；若學校或機構要掛名，需另行決定。

## 沒驗到

- Google 授權畫面實際字樣、帳戶頁「第三方應用程式和服務的存取權」的實際名稱：頁面標「待核對」，需使用者登入後照抄（硬規則 10）。
- Google 品牌驗證是否要求**驗證 `derliang.github.io` 網域所有權**（GitHub Pages 子網域要用 Search Console 驗證，作法是否可行未查證）：發布到「正式版」後才知道，可能需要使用者實際操作。
