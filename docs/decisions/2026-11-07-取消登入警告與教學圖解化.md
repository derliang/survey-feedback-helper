# 取消 Google 登入帳號類型警告；教學改圖解（2026-11-07）

> 使用者 2026-11-07 的兩項裁示與派工。承接 [取消帳號限制](2026-11-01-取消帳號限制.md)（當時只是設計上取消限制，尚未實證）。

## 一、Google 登入帳號類型的限制與警告全部拿掉

- **使用者裁示（2026-11-07）**：Google 登入已實證，**不需要個人 Gmail**，學校帳號與其他 Google 帳號都能登入。先前所有「請改用個人帳號／私人 Gmail」的限制與警告請拿掉。
- **範圍（依 `src/` 現況盤點，施工時以實際 grep 為準）**：
  - 「學校管理員限制第三方應用程式，請換個人帳號」一類的說明與教學項目（`src/ui/strings.ts` 教學段、`popup_closed` 說明，及 `strings.en*.ts` 對應英文）。
  - 「登入學校帳號時學校管理員可能看得到，名單要保密請用個人帳號」這類警告（`strings.ts` 隱私段 `s4`）：**屬隱私提醒，是否整句刪除需使用者確認**，施工時先列出、不自行決定刪或留（回報調度員）。
  - 帳號說明的前導句改成不分帳號類型的正面寫法（例如「選放著這份試算表、或有權限開它的那個 Google 帳號」），不再出現「個人帳號、學校帳號都能用」這種暗示曾有限制的句子（可視為保留的中性句，由施工者斟酌，須一致）。
  - 「範本表單需要用私人 Gmail 建立」是**範本表單建立者**的內部說明（`guide-config.ts`、`templateSoon`），與使用者登入無關，**不動**。
- **不動**：「登入視窗被擋（popup_failed_to_open）」的處理——那是瀏覽器彈出視窗問題，不是帳號類型限制。
- **同步**：e2e、英文字串、`docs/design/DESIGN.md`／模擬頁中仍寫「僅限私人 Gmail／學校帳號被擋」的描述若有，只改文字敘述，不重畫（重畫走設計員）。

## 二、所有教學流程改成「自畫圖解＋簡單文字」

- **使用者裁示（2026-11-07）**：目前教學是文字講解，改成自己畫圖搭配簡單文字的圖解，**所有教學流程**都要。
- **走設計員流程**（硬規則 11）：設計稿由設計員出，使用者確認後才施工；施工不得先於確認。
- **原則**：圖一律自畫示意（SVG／HTML），**不用 Google 或 Microsoft 的截圖**（著作權與日後介面改版）；圖上按鈕與選單名稱必須與實際介面一致（硬規則 10），無法核對的標「待核對」並記錄於 `docs/design/Google介面核對紀錄.md`；文字力求簡短。
- **承接**：Google 教學頁改版（共同前置＋兩條並列流程）已有設計稿與施工（見 [Google教學改版設計](2026-11-07-Google教學改版設計.md)）；圖解設計以那套資訊架構為底，不推翻。
