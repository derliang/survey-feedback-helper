# xlsx 輸出與分支保護（2026-11-01）

使用者以問題卡裁示：

1. **xlsx 輸出沿用自寫 fflate**（與讀取一致）。原因：ExcelJS 4.4.0 的間接相依 `buffers`（無授權欄位）、`chainsaw`（"MIT/X11"）會讓 `check:licenses` 失敗，且套件較大。代價：儲存格樣式、欄寬等格式功能要自己做，工時較多。被否決：ExcelJS（需放寬授權檢查清單）。
2. **main 先不設分支保護**。原因：已移除 GitHub Actions，沒有 CI 可設必要狀態檢查；合併前由調度員附本機 `npm run ci` 證據把關，發布一律等使用者說「發布」（見 [Pages 改本機發布](2026-11-01-Pages改本機發布.md)）。可日後重議（只要求 PR、不要求狀態檢查）。
