# 選課分組志願：使用者裁示（2026-11-01）

需求草案見分支 `designer-course` 的 `docs/decisions/2026-11-01-選課分組志願需求草案.md`。使用者經問題卡裁示（皆採草案建議）：

1. 排序題：Google 表單「選擇題方格」（志願方格，每欄限選一個回應）——先前已定。
2. 名額：在小幫手內填（解析課程後讓老師填名額上限；課程名自動比對表單選項）。
3. 超額分法：逐志願輪＋可重現抽籤（沿用票選抽籤種子）；未分到者進下一志願輪。
4. 優先名單：做（老師可指定少數學生優先）；最少開班人數：只標示「建議停開」，不自動重分。
5. 第一版輸出：分組名單＋待安排名單＋志願命中統計；公布版與個人通知單後續再加。
6. 未回答（志願數 N、課程數、一次性或重複使用）：施工先以 N=3、課程≤8、一次性使用為預設，介面不寫死，之後可調。

被否決／不做：依優先順序分配、延遲接受演算法、自動停開重分、成績加權。
