## 做了什麼

| 項目 | 做法 | 檔案 |
|---|---|---|
| PWA 離線 | 建置時由 Vite 外掛列出 `dist` 內的程式檔（JS、CSS、首頁、圖示）寫成 `precache.json`，並把檔案雜湊填進 `sw.js` 的 `__BUILD_ID__`；Service Worker 安裝時預先快取，離線時先找快取、連不上導覽就開首頁。字型與 wasm 維持原本「用到才快取」。**只快取程式本身，不攔截、不快取任何問卷資料。** 只在正式建置註冊。 | `vite.config.ts`、`public/sw.js`、`public/manifest.webmanifest`、`public/icons/`、`scripts/make-icons.mjs`、`src/main.tsx` |
| 深色模式 | tokens 的深色版早已存在；本輪確認 `app.css` 沒有寫死色碼、設定頁「外觀」三選一可用，並加 e2e（切換、跟隨系統）。紙張維持淺色，圖表另存圖片也一律淺色。 | `tests/e2e/polish.spec.ts` |
| 鍵盤操作 | 彈出面板 Tab 循環（不跑到後面頁面）、Esc 關閉並還原焦點；第一個 Tab 是「跳到主要內容」；設定頁寫出快捷鍵說明。 | `src/ui/parts/parts.tsx`、`src/ui/views/Misc.tsx` |
| 動態與轉場（M1） | 按鈕／籌碼／列顏色漸變 160ms；彈出面板與遮罩進場 220ms（手機由下、平板由右、桌機淡入放大）；`prefers-reduced-motion` 全部關閉。 | `src/ui/app.css` |
| 圖表另存圖片 | 每張圖下方「另存圖片（JPG）」：畫面圖表（CSS 變數、透明底）換成紙本淺色版再畫成 JPG，檔名為圖表標題。 | `src/ui/chart-svg.ts`、`src/ui/chart-png.ts`、`src/ui/views/StatsView.tsx` |
| Google 表單設計教學頁 | 首頁左欄文字連結「Google 表單怎麼設計」進入，動態載入。五區段：匯出成 Excel（用字照[核對紀錄](../design/Google介面核對紀錄.md)）、改用私人 Gmail、五個技巧與題型對照、範本表單、示範資料。 | `src/ui/guide/` |
| 示範資料（R-001） | 只放教學頁。載入 41 人虛構資料直接進準備資料；頂端標「示範資料」；不比對最近的問卷、不存進資料夾；重新開始即清除。 | `src/app/store.ts`（`openDemoTable`）、`src/ui/guide/GuideView.tsx` |
| 快速範本 | 首頁左欄文字連結「用快速範本」進入。六個範本（活動滿意度、家長意見、教學回饋、學習自評、報名點名清點、班規議題票選）可看題目、複製題目清單。用範本題目建的表單匯出後開啟，標題相符就問「是不是用範本做的」並帶入類型、欄位對應、量表範圍（沿用原本「是不是之前的問卷」比對，門檻 0.8）。 | `src/app/quick-templates.ts`、`src/app/store.ts` |
| 英文介面骨架 | 文字集中在 `strings.ts`；`strings.en.ts` 只翻主要畫面（標題、步驟、首頁、設定、資料夾要點），其餘退回繁體中文；選英文時才動態載入，換語言就地改寫 `strings`，`<html lang>` 同步。設定頁「語言」切換，偏好存在瀏覽器介面偏好。 | `src/ui/locale.ts`、`src/ui/strings.en.ts`、`src/storage/prefs.ts` |
| 常用評語（R-021、R-022、R-042） | 老師評語欄下方：六類各 5 句籌碼（短標題、懸停看整句）、分類頁籤、搜尋；點一下插在游標處並把 `{姓名}` 換成這位同學；「存成常用評語」（有選取存選取、學生名字自動換回 `{姓名}`、重複不新增、每類最多 8 句）；整理模式可改寫、刪除、上下移、新增分類。評語庫存在設定檔（`phrases` 欄位；沒改過就用內建，舊設定檔照常讀）。 | `src/app/phrases.ts`、`src/ui/views/Phrases.tsx`、`src/storage/` |

## 沒做、或做了折衷（需要知道）

1. **範本表單（G4）沒有按鈕**：需要使用者用私人 Gmail 建「活動滿意度」虛構表單並取得「建立副本」連結，填進 `src/app/guide-config.ts` 的 `TEMPLATE_FORM_URL`（空字串時教學頁顯示「準備中」）。Claude 不代建。
2. **Google 表單題型名稱仍標「待核對」**：簡答、選擇題、核取方塊、線性刻度、段落、單選方格，以及表單「發布」字樣，沒有實際走過介面；教學頁與快速範本畫面都明寫「待核對」，沒有自己編。已核對的字（「回覆」「連結至試算表」「建立新試算表」「建立」「檔案」→「下載」→「Microsoft Excel (.xlsx)」）照核對紀錄。
3. **英文只是骨架**：約 60 個字串；Google 介面的英文選單名稱沒有核對，一律不翻（硬規則 10）；教學頁、統計、輸出頁目前仍是繁體中文。
4. **動態只做「進場」**：M1 表的出場（160ms）、展開收合（200ms）、拖曳浮起沒有做（卸載時機要改元件，且編輯器目錄這輪不碰）。
5. **離線時的輸出**：程式本身離線可開；輸出 PDF 用的字型（約 5.4 MB）與 wasm 要先輸出過一次才會存起來（預先快取會讓第一次安裝多下載 5 MB，不值得）。
6. **範本辨識門檻沿用 0.8**：老師改了範本題目，標題相似度低於 0.8 就不會自動認得，改走一般欄位對應。
7. **編輯器目錄（`src/ui/editor`、`src/editor`）完全沒動**（settings-backup 同時在改）。深色模式下編輯器紙張／檯面的樣式（A8、A9）屬該目錄，待它併入後另做。
8. 實機驗證（iOS Safari 的 PWA 安裝、鍵盤、離線）、Teacher Hub 卡片轉正：不在這個分支的範圍。

## 我替你決定的事

- Service Worker 版本用「檔案清單雜湊」，不手動維護版本號。
- 常用評語庫放進設定檔而不是另開檔案（跟著資料夾／下載備份走；沒資料夾時走既有的「設定有更新，還沒保存」提示）。
- 教學頁的「示範資料」直接用既有的 `buildSampleDataset`（41 人、seed `demo`），不新增資料檔。
- 英文預設不自動偵測瀏覽器語言，預設仍是繁體中文。
