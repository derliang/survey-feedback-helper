| Sheets API 配額 | 讀取每專案每分鐘 300 次、每使用者每分鐘 60 次；超過回 **429**。 | [Sheets 限額](https://developers.google.com/workspace/sheets/api/limits) |
| Drive API 配額 | 每專案每分鐘 100 萬單位、每使用者 32.5 萬單位；超過回 **403**（User rate limit exceeded）或 **429**。2026-05-01 後建立的專案用新配額。 | [Drive 限額](https://developers.google.com/workspace/drive/api/guides/limits) |

| Picker | 網頁版是用戶端 JS 程式庫（PickerBuilder），用 `setOAuthToken` 傳權杖；本頁沒有談 API 金鑰、`setAppId`、選檔是否授予 `drive.file` 存取、費用——**待實測**（`drive.file` 涵蓋使用者用 Picker 選給本程式的檔案，見 [Drive 授權範圍](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)）。 | [Picker 概觀](https://developers.google.com/workspace/drive/picker/guides/overview) |

4. 不綁帳單時超額的實際行為。

## 實作決定（A 軌，可改回）

- 程式在 `src/google/`，所有外部依賴（載入腳本、`fetch`、Picker）都走介面，單元測試用假實作；GIS 與 Picker 腳本**動態載入**，不進首頁 bundle。
- 用戶端 ID、API 金鑰、專案編號只從 `VITE_GOOGLE_*` 環境變數讀入（建置時注入，**不寫進 repo**）；缺任何一項，整個 Google 功能停用並顯示友善說明。注意 OAuth 用戶端 ID 與受限網址的 API 金鑰本來就會出現在公開網頁，這是 Google 的設計；金鑰安全靠「限 Pages 網址、只開三個 API」，不靠隱藏。
- 帳號判斷：只看信箱網域，`gmail.com`／`googlemail.com` 放行，其餘一律擋下（無「仍要繼續」），取不到信箱也擋（不讀任何檔案）。
