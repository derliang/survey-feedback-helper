## 套用規則（確認後給施工）

- 只改使用者看得到的字串（UI、英文、匯出檔內文字）；`seed`、`reversed`、`trim` 等程式識別名不動。
- 同一詞所有出現處一次改完，改後 `grep` 舊詞應只剩註解與識別名；測試與 e2e 的舊字一併更新。
- 按鈕與標籤變長者先 320px 實測，換行就保留原文並回報。
- 套用後 `npm run ci` 全綠，PR 附逐筆結果與 `grep` 證據。
