# 逐頁狀態覆蓋稽核（2026-11-14）

> 對象：v0.2.11（`main` b003838）。方法：`npm run build` 後以 `scripts/serve-dist.mjs` 提供，Playwright 腳本（一次性，未納入 repo）在桌機 1280、平板 820、手機 390 三種寬度逐頁操作，抓取標題、停用按鈕、`role=alert／status／dialog`、無名稱控制項、橫向溢出、小於 40px 的控制項，並讀頁面文字；僅用虛構資料；未碰真實 Google 登入。
> 範圍限制：本輪主要深入桌機；平板、手機跑了五種問卷流程與錯誤檔，其餘頁面（設定、範本、教學、英文介面、編輯器、審稿）以桌機＋手機為主。**不含**真機、真實 Word／Excel 開啟、Google OAuth。版面美醜歸設計員，只一行帶過。

## 1. 首頁（選擇要整理的問卷）

- **已核對**：正常（無資料夾）；「開啟試算表」停用並有說明（未設定 Google 連線）；錯誤檔（PDF、空檔、只有標題、損毀 xlsx）各有 `role=alert` 與具體文字；設定檔錯誤（`bad.json`）顯示「這不是問卷小幫手的設定檔，或內容已損毀」；Tab 順序合理，首個是「跳到主要內容」；英文版齊全（僅 B3）。
- **Bug**：無（B3 見英文）。
- **未核對**：有資料夾時的「最近的問卷」清單、重新授權流程（需 File System Access 實機）。
- **缺少 e2e**：已有 `app.spec`、`privacy.spec`；缺「損毀 xlsx 的錯誤文字」（`survey-flow` 只測空檔、只有標題、不支援格式）。

## 2. 準備資料（問卷類型 → 欄位對應 → 學生名單 → 資料檢查）

- **已核對**：步驟停用與「請先完成前一步」說明；問卷類型建議與「怎麼判斷的」；欄位對應「待分類」面板（`role=dialog`）；票選幹部缺選擇題時 `role=alert` 擋下「完成對應」；名單貼上後預覽、「加入名單」「下一步：名單對照」停用邏輯；名單對照頁的四個分頁計數與「複製尚未填答的學生名單」；資料檢查的「2 類待處理」與各類別「沒有發現／正常」。
- **Bug**：無新增。
- **文字與功能**：進度摘要「完成 0／4 · 請先確認問卷類型…」與步驟「學生名單（選用）」並列計入 4 項，選用項被算進分母，老師可能以為必做（低，文案建議交詞彙表工作）。
- **缺少 e2e**：已有 `import-confirm`、`app`、`survey-flow`；缺「手機寬度完整走過名單對照」。

## 3. 統計（各問卷類型）

- **已核對**：意見調查（評分、單選、複選、開放意見；一筆、全空、混入文字分數）；報告回饋（全班總覽、個人、自評比較、審稿、歷次趨勢）；票選幹部（職位、計票、同票抽籤、可疑投票）；單選題；選課（未分配時輸出頁提示「先到名額與分配」）。
- **Bug**：
  - B1（#90）：每種問卷、無資料夾時，統計頁皆顯示「尚未成功儲存」警示，連 0 則意見也顯示。
  - B5（#94）：整欄空白的評分題從題目清單消失，無說明。
- **文字與功能**：票選同票訊息直接顯示內部抽籤編號「抽籤-xxxxxxxx|3」，老師看不懂（低；為可重現而設，但可改成「抽籤編號」說明）；混入文字的「評分」欄被視為單選題而不提醒，資料檢查頁未標示（低）。
- **缺少 e2e**：無「整欄空白」「一筆回覆」「無資料夾時審稿警示是否合理」；選課的完整統計已由 `course.spec` 涵蓋。

## 4. 審稿（採用／隱藏／改寫／老師評語／用詞清單）

- **已核對**：採用後未審計數 4→3；用詞清單加入／移除有 `aria-label`（「移除「笨」」）；常用評語插入有 `aria-label`；手機把「下載審稿進度」換成「儲存到檔案」；輸出頁學生版在未預覽前 PDF／Word／列印／zip 皆停用，並有「還有 N 則留言沒審稿」與個資提醒。
- **Bug**：B1。
- **無障礙**：同一則留言的「採用這則留言／隱藏／改寫」三顆按鈕，aria-label 不含留言內容，同頁多則留言時朗讀名稱相同（低；建議加上留言摘要或所屬題目）。
- **缺少 e2e**：已有 `stats.spec` 的審稿；缺「採用後的即時回饋（無 toast／status 變化）」。

## 5. 輸出（Excel／Word／PDF、學生版預覽、批次）

- **已核對**：統計報告三種格式；報告回饋的教師／學生／家長版切換、班級總表、個人回饋單、範本選擇、「全部 N 位（打包 zip）」；成功訊息「已下載「…」。」會出現在 `role=status`。
- **Bug**：B4（#93）：產生期間按鈕只停用，無進度字樣；第一次載入約 5 MB 字型時尤其明顯。
- **未核對**：實際開啟 Word／Excel／列印預覽（需真機）；zip 內容。
- **缺少 e2e**：沒有「產生中」狀態；`export.spec` 只一個測試，格式內容檢查主要在 `survey-output`。

## 6. 範本與版面、編輯器

- **已核對**：範本庫（內建／我的篩選）、點範本卡進入編輯器、桌機區塊清單（↑↓、加入區塊、頁面設定 A4／A5／Letter 等）、手機三模式（預覽／區塊清單／編輯，捲動模式說明）、「編輯屬性」在未選取區塊時停用、無資料夾時的備份提示（`role=status`）。編輯器所有可見按鈕皆有名稱。
- **Bug**：B2（#91）：英文介面整頁中文。
- **無障礙**：編輯器頁沒有 `h1`（桌機只有 `h2` 區塊，手機沒有任何標題），輔助科技無法由標題辨識頁面（低，未開 Issue）。
- **缺少 e2e**：`editor*.spec` 涵蓋互動，缺英文介面、缺標題結構。

## 7. 設定與備份

- **已核對**：隱私三句、資料夾、預設輸出設定三層、備份下載、備份還原選到損毀檔時 `role=alert`「無法讀取備份檔。請確認檔案由本程式產生，或重新下載備份。」、外觀（跟隨系統／淺色／深色）、語言、離線使用、鍵盤、瀏覽器支援；英文版齊全。備份區有個資提醒 `role=status`。
- **Bug**：無。
- **未核對**：真實資料夾授權、備份「合併／覆蓋」的實際寫入（已由 `settings-backup.spec` 部分涵蓋）。
- **缺少 e2e**：損毀備份檔的錯誤訊息。

## 8. Google 表單教學、快速範本、示範資料

- **缺少 e2e**：示範資料載入後走到統計、輸出的流程（`polish.spec`、`guide.spec` 只到載入與標記）。

## 9. 統計方法說明、重新開始（確認視窗）

- **已核對**：方法頁含資料來源、欄位對應、計入與排除、計算方式、可重現性、提醒；「重新開始」開 `role=dialog`「清除目前問卷，重新開始」，Esc 可關閉。
