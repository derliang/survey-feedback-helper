日期：2026-11-01。**設計稿已出：[DESIGN.md 5.27](DESIGN.md) 與 `mockups/*-選課分組志願.html`，視覺以它們為準，本文僅保留線框說明。** **需求已定案**（見[裁示](../decisions/2026-11-01-選課分組志願裁示.md)與[需求草案](../decisions/2026-11-01-選課分組志願需求草案.md)）；本文仍是文字線框（非視覺稿），施工以此為版面依據，預設 N=3、課程≤8、介面不寫死。第一版輸出只含分組名單、待安排、命中統計，第 6 節的公布版與個人通知單為後續。這裡只用文字線框說明資訊配置與操作，不使用最終視覺。定案後才依 [DESIGN.md](DESIGN.md) 出手機、平板、桌機模擬頁。元件一律沿用 DESIGN.md 第 4 節（`.tile`、`.brow`、`.sheet`、`.chip`、`.actbar` 等），課程與學生皆為虛構。

## 1. 步驟 2：對應欄位（新增「志願」角色）

手機：沿用 `.rowbtn` 欄位列。

```
[志願方格] 第一志願  範例：微積分      [志願 1 ▸]
[志願方格] 第二志願  範例：生物實驗    [志願 2 ▸]
[志願方格] 第三志願  範例：地球探索    [志願 3 ▸]   ← 順序可調
```

- 欄名含「第一」「第二」或 `[第1志願]` 時自動猜順序，猜的列標「請確認」。
- 用方案 A／C 的方格匯出時，同一題的各列合併成一組志願；對不上的欄位單獨列出。

## 2. 步驟 3a：名額（手機）

```
┌ 課程名單與名額 ────────────────┐
│ 微積分     名額 [ 30 ]  最少 [ 10 ] │
│ 生物實驗   名額 [ 25 ]  最少 [  — ] │
│ 地球探索   名額 [ 35 ]  最少 [  — ] │
│ ⓘ 有 1 個課程名與表單選項對不上     │
│   「地球 探索」→ 合併到「地球探索」？  │
├ 底部操作列 ─────────────────────┤
│ [上一步]          [開始分配]        │
└──────────────────────────┘
```

- 名額用數字輸入（48 高）；「最少」選填。
- 總名額小於學生數時，頂端 `.notice` 警示：「名額合計 90，填答 96 人，至少 6 人會進待安排」。

## 3. 步驟 3b：分配結果（手機）

```
數字磚： 已分配 90 / 96 │ 第1志願達成 71% │ 待安排 6
種子：4821  [重新抽籤] [固定結果]

微積分    ■■■■■■■■■ 30/30  已滿（報名 41）
生物實驗  ■■■■■■□□□ 22/25
地球探索  ■■■■■■■□□ 28/35
待安排    6 人 ▸
```

- 每列是 `.brow`：名稱＋「人數／名額」，長條在下；已滿用警示標籤「已滿」，不只靠顏色。
- 點課程列 → 底部面板 `.sheet`：該課名單（座號、姓名、第幾志願標籤）；每列有「移到…」，再開一個課程選單。**不靠拖曳**。
- 點「待安排」→ 同樣面板，列出原因（志願都滿了／未填）與「放入…」。
- 手動移動後，課程若超過名額，該列變警示並說明「超額 1 人」，仍可保留（老師決定）。
- 底部主按鈕：「確認，下一步」；次按鈕：「上一步」。

## 5. 桌機（≥1024）：三欄工作台

```
┌ 課程（左）──────┬ 名單（中）────────────┬ 規則與種子（右）──────┐
│ 微積分  30/30   │ 搜尋學生…                │ 分配方式：逐志願輪       │
│ 生物實驗 22/25  │ 座號 姓名 志願 動作       │ 超額處理：可重現抽籤     │
│ 地球探索 28/35  │ 可拖曳到左欄課程          │ 種子 4821  [重抽]        │
│ 待安排   6      │ （拖曳之外一律有「移到」）│ 優先名單 2 人 [編輯]     │
│                 │                           │ 分配紀錄 [檢視]          │
└─────────┴──────────────┴──────────────┘
```

- 桌機拖曳是加分功能，必須另有「移到…」按鈕與鍵盤操作（無障礙）。
- 「分配紀錄」顯示種子、規則、名額、時間，供方法說明頁使用。

## 6. 步驟 4：輸出

沿用現有輸出頁的檔案卡：分組名單（xlsx，每課一張工作表＋總表）、待安排名單、志願命中統計；選用：公布版（去識別化，輸出前提醒並必須預覽）、個人通知單。

## 7. 空狀態與錯誤

- 沒有任何志願欄被對應：提示「請先在步驟 2 指定哪些欄位是志願」，附回上一步按鈕。
- 全部名額為 0 或未填：主按鈕停用並在旁說明原因。
- 名單外的學生填了表單：沿用名單對照，列出讓老師決定納入與否。
