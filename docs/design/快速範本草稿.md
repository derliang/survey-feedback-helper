# 快速範本預設內容草稿（R-009）

> 2026-11-01 由設計員擬稿，**待使用者修改後才定稿**（同〈預設常用評語草稿〉的做法）。畫面見 [手機](mockups/手機-第五輪.html)、[平板](mockups/平板-第五輪.html)、[桌機](mockups/桌機-第五輪.html) 的 Q1／Q2。決定背景：[頁面裁示 R-009](../decisions/2026-10-31-頁面討論裁示.md)——v0.1 維持三種獨立類型，新情境做成快速範本；選課分組志願需要排序題與名額，不在此列。

## 範本是什麼、不是什麼

- 範本 = **題目清單草稿**（老師照著在 Google 表單建，或用教學頁的範本表單複製）＋ **匯出後的預設值**（問卷類型、欄位用途、量表範圍、預設圖表）。
- 不含任何學生資料；範本只是預設值，欄位對應畫面仍可改。
- 類型只有既有三種：意見調查、票選幹部、報告回饋。六個範本裡五個是「意見調查」、一個（班規議題票選）是「票選幹部」。
- 題型名稱（選擇題、核取方塊、線性刻度、段落、簡答）是 Google 表單的介面字樣，**尚未實際核對，標「待核對」**；實作前要走過建立題目的畫面再照抄。
- 欄位用途名稱（時間戳記、評分、開放意見…）沿用程式的欄位對應：見 `src/ui/strings.ts` 的 `mapping.roles`。

## 共同欄位（需要識別時才放）

需要對名單時，表單前三題固定為：班級（簡答）、座號（簡答）、姓名（簡答）；不需要時（匿名回饋）整組拿掉。匿名意見調查**不要**放姓名題，這會影響老師審稿與去識別化的需求（見[進階統計定義](../decisions/2026-11-01-進階統計定義.md)）。

## 1. 活動滿意度（意見調查，6 題，匿名）

對象：學生或參加者。情境：遠足、校慶、營隊、班級活動。量表：1～5（非常不滿意～非常滿意）。

1. 整體來說，我對這次活動感到滿意（線性刻度 1～5）
2. 活動內容有趣、有收穫（線性刻度 1～5）
3. 時間與流程安排得宜（線性刻度 1～5）
4. 場地與準備工作讓我覺得舒服（線性刻度 1～5）
5. 我願意再參加類似的活動（線性刻度 1～5）
6. 最喜歡的部分與可以更好的地方（段落）

預設圖表：量表堆疊橫條；開放題留言依主題分組。

## 2. 家長意見（意見調查，6 題，匿名或具名自選）

對象：家長。情境：班親會、聯絡簿、親師溝通方式。量表：1～5（非常不同意～非常同意）。

1. 我清楚了解孩子在班上的學習狀況（線性刻度 1～5）
2. 班級聯絡方式（通知、聯絡簿）讓我方便掌握訊息（線性刻度 1～5）
3. 我覺得老師重視孩子的個別需求（線性刻度 1～5）
4. 我希望班親會或聯繫的頻率（選擇題：更常／維持／更少）
5. 最希望老師多協助的方面（核取方塊：學習、生活、人際、情緒、其他）
6. 還有什麼想對老師說的（段落）

預設圖表：第 1～3 題量表堆疊橫條；第 4 題長條；第 5 題複選長條（比例以填答者為基準）。**提醒**：留言可能寫到孩子或其他家長的名字，輸出前依〈去識別化提醒〉預覽。

## 3. 教學回饋（意見調查，7 題，匿名）

對象：學生。情境：期中、期末的課堂教學意見。量表：1～5（非常不同意～非常同意）。

1. 老師上課的重點清楚（線性刻度 1～5）
2. 上課的步調我跟得上（線性刻度 1～5）
3. 作業的份量與難度適中（線性刻度 1～5）
4. 我敢在課堂上提問或發言（線性刻度 1～5）
5. 最有幫助的課堂活動（核取方塊：講解、分組討論、練習題、報告發表、其他）
6. 希望老師繼續的一件事（段落）
7. 希望老師調整的一件事（段落）

預設圖表：量表堆疊橫條；若有分班可用交叉熱圖。**提醒**：對老師本人的意見，輸出給學生看的版本只放彙整。

## 4. 學習自評（意見調查，6 題，具名，可選）

對象：學生自己。情境：單元結束後自我評估。量表：1～5（完全不是這樣～完全是這樣）。

1. 我能用自己的話說明這個單元的重點（線性刻度 1～5）
2. 我完成了老師交代的練習（線性刻度 1～5）
3. 我有遇到不懂的地方會想辦法弄懂（線性刻度 1～5）
4. 我和同學合作得很順利（線性刻度 1～5）
5. 這個單元我進步最多的地方（段落）
6. 我接下來想加強的地方（段落）

預設圖表：個人回饋單的雷達圖（與全班平均並排）；歷次趨勢可比較不同單元。具名時前三題用班級、座號、姓名。

## 5. 報名點名清點（意見調查，5 題，具名）

對象：學生或家長。情境：活動報名、秋遊參加與否、統購清點。不是量表，沒有評分。

1. 班級（簡答）
2. 座號（簡答）
3. 姓名（簡答）
4. 是否參加（選擇題：參加／不參加）
5. 備註，例如飲食禁忌（段落）

預設做法：欄位對應把「是否參加」設為選擇題；名單對照直接顯示「還沒回覆的人」（可複製名單）；統計只看人數與備註，沒有平均。

## 6. 班規議題票選（票選幹部，5 題，具名）

對象：學生。情境：班規修正案、班級活動主題、座位排法等多個議題各投一票。類型是「票選幹部」，把每個議題當成一個「職位」，選項是贊成、反對、沒意見。

1. 班級（簡答）
2. 座號（簡答）
3. 姓名（簡答）
4. 議題一的立場（選擇題：贊成／反對／沒意見）
5. 議題二的立場（選擇題：贊成／反對／沒意見）

預設做法：防弊檢查（同人多票、自投）照常；「自投」對議題不適用，預設關閉；同票處理預設「老師指定」，不抽籤；有幾個議題就加幾題。**待使用者確認**：把議題票選塞進「票選幹部」類型是否可接受，或要另做獨立類型（目前裁示是不做）。

## 待使用者確認

1. 六個範本的題目與量表文字是否合用、有沒有要加減的情境。
2. 快速範本的入口放哪裡：設計稿暫放首頁左欄按鈕列下方的文字連結「用快速範本」與教學頁；也可只放教學頁。
3. 班規議題票選用「票選幹部」類型是否可接受（見範本 6）。
