## 1. 設計原則

1. **手機單手優先**（使用者決定）。老師常用手機操作，所以先設計 390px 寬，平板與桌機從它延伸。主要動作放畫面底部，拇指好按。
2. **一次一個步驟**。流程固定四步：開啟、對應欄位、統計、輸出；每個畫面只有一個主按鈕。理由：老師不是技術人員，也常被打斷。
3. **清爽的數據工具風**（使用者決定）。明亮中性底、一個鈷藍強調色、少裝飾；重點是數字與圖表清楚。不是學院風，也不是商品目錄。
4. **數字要能對照，不單靠顏色**。長條旁一定有名稱與數字；狀態一定有文字或圖示。理由：色盲友善，也方便黑白列印。
5. **誠實說明資料去向**。第一屏就寫標準句（見〈6. 文案語氣〉）。理由：硬規則「資料不落地」，而且檔案放在雲端時要講清楚例外（R-005）。

## 2. Tokens

### 色彩

淺色／深色並列，深色依 `prefers-color-scheme` 自動切換，也支援 `data-theme` 強制切換。實際值以 [tokens.css](tokens.css) 為準。

| token | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--paper` | `#f4f5f7` | `#0e1014` | 頁面底 |
| `--card` | `#ffffff` | `#171a20` | 卡片、導覽列、輸入框底 |
| `--sunk` | `#eceef2` | `#0b0c10` | 凹陷底：分段控制軌道、進度軌道、停用 |
| `--ink` | `#14171f` | `#eceef3` | 主要文字 |
| `--ink2` | `#444b5a` | `#b9bfcc` | 次要文字、說明 |
| `--ink3` | `#5b6373` | `#8f97a8` | 輔助文字、控制項外框 |
| `--line` / `--line-soft` | `#cfd3dc` / `#e3e6ec` | `#2b303a` / `#20242c` | 強分隔線／卡片外框、列分隔（皆為裝飾，控制項外框改用 `--ink3`） |
| `--accent` | `#2554d8` | `#3d68f0` | 強調：主按鈕、目前步驟、選取（唯一強調色，鈷藍） |
| `--on-accent` | `#ffffff` | `#ffffff` | 強調底上的文字 |
| `--accent-soft` | `#e7edff` | `#1a2850` | 選取底、一般提示底 |
| `--accent-ink` | `#1b3fa6` | `#9db8ff` | 強調色文字、連結 |
| `--ok` / `--ok-soft` | `#17713f` / `#dcf1e3` | `#6fd39a` / `#12291c` | 成功 |

規則：
- 強調色只有鈷藍一個。深色版的按鈕底用飽和的藍搭白字，不用粉彩色；淡底（`--accent-soft`）只用在選取與提示。表面一律中性灰，不帶綠或其他色調。成功、警示、錯誤是語意色，不算強調色，不可拿來當裝飾。
- 文字用不透明的 token，不用透明度或混色把字變淡。已用 `tokens.css` 的值算過對比：文字對背景至少 4.5:1，淺色深色都通過；圖表資料色對卡片底至少 3:1。
- 輸出文件（回饋單）的色彩另有一組 `--doc-*`，見〈5.5〉。

### 字型

| 用途 | 字型 | 字級／行高 | 字重 |
|---|---|---|---|
| 介面全部 | `Noto Sans TC`，備援 `PingFang TC`、`Microsoft JhengHei`、`Heiti TC`、system-ui | 見下表 | 400／600／700 |
| 數字與表格數值 | 同上，加 `font-variant-numeric: tabular-nums` | 依用途 | 700 |
| 檔案名稱、代碼 | `ui-monospace`、`SF Mono`、`Consolas` | 13 | 400 |

| token | 字級 | 用途 |
|---|---|---|
| `--fs-3xl` | 32 | 只用在首頁標題「開啟試算表」 |
| `--fs-2xl` | 28 | 頁面大標題、統計大數字 |
| `--fs-xl` | 22 | 區段標題、畫面標題 |
| `--fs-lg` | 18 | 卡片標題、面板標題 |
| `--fs-md` | 16 | 內文與輸入（手機輸入框不得小於 16，避免 iOS 自動放大） |
| `--fs-sm` | 14 | 說明、提示、列表次行 |
| `--fs-xs` | 13 | 標籤、輔助文字 |

字級表外的固定值：`.btn-sm`、`.seg`、`.chip` 用 15；手機與編輯器頂端列標題用 17。

行高：內文 1.65（`--lh-body`），標題 1.3（`--lh-tight`）。標題加 `text-wrap: balance`。

**介面一律用系統字型，不載入網路字型**（使用者確認）。原因：全專案零費用、離線可用（v1.0 PWA）、手機載入快、不向第三方（如 Google Fonts）傳送使用者的 IP。只有「文件預覽與 PDF 輸出」使用內嵌的 Noto Sans TC 子集（見技術決定）。

### 間距、圓角、點擊區、陰影、動態

- 間距用 4 的倍數：`--sp-1`…`--sp-7` = 4、8、12、16、24、32、48。並排元素用 flex／grid 加 `gap`。
- 圓角：`--r-sm` 8（按鈕、輸入、選項）、`--r-md` 12（卡片、面板、提示）、`--r-lg` 20（底部彈出面板上緣）。籌碼為全圓（999）。
- 點擊區：預設 `--tap` 48，**任何可點元件不得低於 `--tap-min` 44**；相鄰可點元件間距至少 8。
- 陰影：底部彈出面板與分段控制選取項用 `--shadow`；卡片、數字磚、列、次按鈕加 `0 1px 2px var(--shadow-sm)` 做細微層次，其餘用 1px 外框。
- 動態：`--dur` 160ms，只用在背景與外框顏色；`prefers-reduced-motion` 時關閉。不做進場動畫。

## 3. 版面與斷點

| 範圍 | 版面 |
|---|---|
| 手機 < 600（以 390 為準） | 單欄、一次一個步驟。頂端列（返回、標題、動作）＋步驟進度＋內容＋底部操作列。左右留白 16。面板由下往上。 |
| 平板 600–1023（以 820 為準） | 左右分欄：清單或設定在左、預覽在右；可橫豎切換；面板改成靠側彈出。畫面見 5.11。 |
| 桌機 ≥ 1024（以 1280 為準） | 三欄工作台：資料／預覽／屬性。內容最寬 1240。桌機仍保留 44px 點擊區。畫面見 5.11。 |

- 不得出現橫向捲動；只有表格與程式碼可以在自己的容器內橫向捲動。
- 底部操作列要加安全區：`padding-bottom` 含 `env(safe-area-inset-bottom)`。
- 手機版每個畫面只有一個主按鈕，放在底部操作列；「上一步」為次按鈕，放在主按鈕左側。

## 4. 元件規則

通用：焦點框 3px `--accent`、外移 2px；連結與按鈕的顏色都走 token；停用元件要在旁邊說明原因，不只變灰。

| 元件 | 規則 |
|---|---|
| **按鈕** `.btn` | 高 48（小 44）、圓角 `--r-sm`、字 16 粗體 600。變體：`primary`（強調底，每畫面一個）、`secondary`（卡片底、`--ink3` 外框）、`ghost`（透明底、強調色文字）、`danger`（透明底、紅外框，不用實心紅）。停用：`--sunk` 底、`--ink3` 字。 |
| **圖示按鈕** `.icbtn` | 48×48，一定要有 `aria-label`。圖示線寬 2、圓端點。 |
| **輸入框** `.input` | 高 48、字 16、外框 1px `--ink3`；錯誤用 2px `--bad` 外框加下方紅字說明。標籤在上、提示在下 13px。 |
| **分段控制** `.seg` | 2 到 4 項，各 44 高，凹陷底軌道、選取項為卡片底加強調色文字與細陰影。可用於切換檢視或格式。 |
| **籌碼** `.chip` | 高 44、全圓、單選一組。選取：強調淡底、強調色外框與文字。選項少又要並排時用。 |
| **選項卡** `.rcard` | 單選圓點加主說明與次說明，最小高 64。選取：強調色外框加淡底。要說明每個選項時用。 |
| **標籤** `.tag` | 高 26、圓角 6、不可點。變體：中性、強調、成功、警示、錯誤。 |
| **提示** `.notice` | 圖示加文字，四種：一般、警示、錯誤、成功。可附一個次按鈕。不只靠顏色。 |
| **數字磚** `.tile` | 標籤在上、大數字在下；需要處理的磚用警示色。只在摘要用，不要當裝飾。 |
| **長條列** `.brow` | 名稱與「N 票 · P%」同一列、粗 12 的長條在下。當選用強調色、同票用警示色、其餘用 `--bar-muted`。比例以全部有效票為 100%。 |
| **欄位列** `.rowbtn` | 欄位對應用：左欄位名與範例值、右類型標籤與箭頭，整列可點，最小高 64。需確認的列加警示色外框與「請確認」標籤。 |
| **底部彈出面板** `.sheet` | 圓角上緣 `--r-lg`、把手、標題、選項列（52 高、整列可點）、底部一個主按鈕；背景用 `--scrim` 遮罩，點遮罩關閉。手機版編輯器的屬性面板沿用此元件。 |
| **頂端列** `.appbar`、桌機 `.tb` | 手機高 56；左返回或品牌、中標題、右動作。桌機與平板的設定鈕是齒輪加「設定」（描邊次要按鈕、高 44）；手機只用齒輪圖示並保留 `aria-label`。 |
| **步驟進度** `.stepper`、桌機 `.ws` | 手機：四段進度條加步驟名稱（待改）。桌機：頂端列下方獨立一列，四段各有編號、圖示、文字、完成度與進度軌道；完成換勾、目前用強調色、未到用外框，不只靠顏色。步驟名稱：開啟、準備資料、統計、輸出。 |
| **底部操作列** `.actbar` | 固定在畫面底，主按鈕佔滿剩餘寬度，次按鈕在左。 |

## 5. 頁面規則

### 5.1 步驟 1：開啟問卷

頂端列（品牌、設定）→ 步驟進度 → 標題與一句話 → **整塊選檔大按鈕**（虛線外框、最小高 176）→ 示範資料按鈕 → 隱私提示 → 「怎麼從 Google 表單匯出？」連結 → 底部「下一步」（未選檔時停用）。

### 5.2 步驟 2：對應欄位

檔案資訊列 → 警示提示（「已自動辨識 N 欄，M 欄請確認」）→ 欄位列清單（需確認的排前面或醒目）→ 底部「上一步／下一步」。點欄位列開底部彈出面板，單選題目類型（單選、複選、量表、開放題、略過；姓名、座號等依欄位而定），按「套用」關閉。

### 5.3 步驟 3：統計結果

三塊數字磚（回覆、題目、需檢查）→ 分段控制「題目／名單／檢查」→ 題目卡（左右箭頭換題、題目名稱與類型、長條列、有效票與空白說明）→ 同票提示（附「抽籤決定」，抽籤要能重現、記錄種子）→ 底部「上一步／下一步：輸出」。

### 5.4 步驟 4：輸出

依序：要輸出什麼（班級總表／個人回饋單，選項卡）→ 檔案格式（Excel／Word／PDF，分段控制）→ 給誰看（教師版／學生版／家長版，籌碼）→ 範圍 → 一行白話摘要（「將產生 41 個 PDF，打包成 1 個 zip，約 3.3 MB」）→ 個資保管提示 → 底部「上一步／產生並下載」。選了 Word 時，提示「版面可能與 PDF 有細微差異」（見技術決定〈十一〉）。

### 5.5 個人回饋單色票（溫暖，使用者決定）

「溫暖親切」是個人回饋單的預設主題，使用 `.doc-warm` 的 `--doc-*` token，紙張永遠是淺色：`--doc-paper #fffdf9`、`--doc-ink #33291f`、`--doc-ink2 #66554a`、`--doc-line #ead9c3`、`--doc-accent #a84f00`（琥珀，用於重點數字與標題）、`--doc-accent-soft #ffecd2`、`--doc-leaf #2f6f55`（綠，用於稱讚與優點）、`--doc-leaf-soft #e1f1e8`。圖表沿用 `--d1`…`--d5`。彩色列印才好看，黑白列印要仍可讀（數字與文字都在圖旁）。區塊元件庫下一輪設計。

### 5.6 輸出文件（A4）

輸出文件是本產品的核心成果，要做到：資料豐富、分析有用、容易閱讀、排版精美；量化（平均、中位數、標準差、分布、交叉）與質化（主題、關鍵詞、代表留言）都要清楚呈現（使用者 2026-10-30 強調）。

- **紙張與字級**：A4 直式，邊界約 14 mm、頁尾區 20 mm。列印字級：標題 24 pt、區段標題 15 pt、內文 11–12 pt、表格 10 pt、註解不低於 9 pt。個人回饋單（給學生與家長）內文用 12 pt；教師版報告的表格可用 10 pt。
- **配色**：用 `.doc-warm` 的 `--doc-*`，紙張暖白、文字深褐、強調琥珀、稱讚綠；圖表以藍（同意、領先）與橘（不同意、需注意）為主。五級量表固定為 橘 `#cf5f12`、淺橘 `#eaa06a`、暖灰 `#ddd5c8`、淺藍 `#7f9be3`、藍 `#2554d8`。
- **每個圖形旁一定標數字與文字**，彩色與黑白列印都讀得出來；最高、最低用文字標籤，不單靠底色。
- **每份報告的結構**：摘要頁（4 個數字、自動產生的重點發現、量表總覽）→ 逐題與交叉 → 質化（主題、關鍵詞、代表留言）→ 方法說明。重點發現與數字一律由統計即時算出。
- **統計誠實**：交叉分析的小組人數少時加警語；複選以回收人數為基準並寫明；量表同時給平均、中位數、標準差與 4–5 分比例。
- **三種版本**：教師版（完整、含原文與排名）、學生版（匿名彙整）、家長版（精簡一頁，不含排名與原文）。同一份範本以條件顯示決定區塊。
- **Word**：圓角與陰影改直角，堆疊條、熱圖、對照條轉為圖片，表格與段落為原生；編輯器對不支援的效果標示「Word：轉為圖片／直角」。
- 區塊庫與規格：[mockups/輸出文件-區塊庫與規格.html](mockups/輸出文件-區塊庫與規格.html)。
- 意見調查班級報告（3 頁）：[mockups/輸出文件-意見調查班級報告.html](mockups/輸出文件-意見調查班級報告.html)。
- 票選結果（公告頁＋計票明細，2 頁）：[mockups/輸出文件-票選結果.html](mockups/輸出文件-票選結果.html)。公告版給同學看（不顯示誰投給誰），明細頁給老師存查，含同票抽籤紀錄（種子、時間）與防弊檢查。

### 5.19 桌機補齊：每個手機畫面都有桌機版

使用者要求手機、平板、桌機各自「每一頁都有設計稿」，並要拿桌機畫面逐頁討論功能，所以桌機優先補齊。現在桌機共 65 個畫面（1280），與手機 70 個畫面一一對應，成品頁的桌機分頁依使用順序分 11 組。

模擬頁：[資料進來與檢查](mockups/桌機-資料進來與檢查.html)（D12–D22）、[統計審稿輸出與狀態](mockups/桌機-統計審稿輸出與狀態.html)（D23–D32）、[編輯器範本與專案檔](mockups/桌機-編輯器範本與專案檔.html)（D33–D43）、[雲端防弊與系統](mockups/桌機-雲端防弊與系統.html)（D44–D56）。

- **對應原則**：手機的「底部彈出面板」在桌機一律改成**置中對話框**（寬 480～720，Esc 或「取消」關閉）或**貼在欄位旁的下拉選單**；手機的「一次一頁」改成左清單／中內容／右說明三欄。內容、文案、數字與手機版相同。
- **對話框通則**：右下角主動作放最右，次要動作在左；危險動作（刪除、確定清除）用警示色文字與外框，不用實心紅鈕，並排在最後。
- **新增的桌機畫面**：選檔來源、讀取中、讀不到檔案、瀏覽器過舊、準備資料總覽、問卷類型、欄位用途下拉、報告回饋欄位對應、名單匯入與兩種對照、同票抽籤、複選題、改寫留言、評語與關鍵字、輸出進度、檔名與去識別化、備份與還原、空白、輸出失敗、離開前確認、編輯器的文字區塊屬性／加入區塊／頁面設定／個別學生版本／拖曳排序、範本庫與選單與匯出匯入、專案檔儲存與開啟後、雲端選檔與配額與已連線、票選防弊與同人多票與計票規則、圖表另存圖片、安裝為應用程式、離線與新版本、隱私與關於、第一次載入、清除本機設定。
- **取代**：原 D9（空白與錯誤三合一）拆成三張獨立畫面（讀不到檔案、空白狀態、輸出失敗），讓每個狀態都能單獨討論。
- **尚未做**：平板還缺與手機一一對應的約 50 個畫面（目前 14 個）；桌機的動態與轉場、滑鼠懸停狀態的細節。

### 5.20 2026-10-31 裁示（桌機已套用，手機與平板待改）

裁示全文見[決定記錄](../decisions/2026-10-31-頁面討論裁示.md)。桌機共 78 個畫面；新增 D57–D69 的模擬頁：[圖表與自訂版面](mockups/桌機-圖表與自訂版面.html)，D57、D58 在[資料進來與檢查](mockups/桌機-資料進來與檢查.html)。

- **首頁（方案 1b，使用者 2026-10-31 選定）**：左邊 420 寬的放檔區（淡藍底、強調色虛線、試算表示意圖、`--fs-3xl` 標題、「把 Excel 檔拖到這裡」、「選擇檔案」、匯出教學連結）；右邊最近的專案 2×3 卡片。沒有示範資料與雲端硬碟入口。
- **最近的專案**：首頁 6 張，可依類型篩選，「全部」列出其餘。卡片是類型色塊、名稱、檔名、類型標籤、日期，只記檔案位置與設定，不存統計結果（R-003 做法 A）。檔案不在時標「找不到檔案」。類型色塊用 `--d1` 票選、`--d2` 意見、`--d3` 報告，這是資料色在圖表以外唯一的用途，一定搭配類型文字。
- **完成度**：準備資料是四件事做了幾件；統計是看過幾題；輸出是審稿人數。統計與輸出的算法是提案，實作前確認。
- **選檔來源（D12）**：只留「這台電腦的檔案」「開啟專案檔」。Google 連線在設定頁（D7、D46）；D45 只寫「目前無法使用 Google 連線，請改用本機檔案」，不保證恢復與費用。
- **匯出教學（D14、D57、D8）**：自畫 SVG 共用同一組 `.guide`，圖中文字可翻譯；不用 Google 截圖，不畫商標。
- **準備資料（D16）**：`.vs` 垂直步驟，順序固定：問卷類型、欄位對應、學生名單（選用，虛線）、資料檢查。前兩件完成才解鎖；目前該做的放大並給按鈕；回頭改前面時，後面標「請重新確認」。
- **問卷類型（D17）**：三種獨立類型，下方快速範本籌碼。
- **欄位對應（13b、D18、D19）**：每列可按「不使用」，收到下方 `offgroup`，仍看得到、可加回。
- **名單（D20、D58）**：同一班／混班兩個分頁。同一班手填班級、每行一位姓名、座號自動補，姓名前的數字當座號；預覽表可改座號、插入缺號，同名標示。混班貼三欄，缺班級或座號的列標出來請老師補，不補不猜。
- **以人為單位的明細**：一律班級、座號、姓名，單班時班級用淡字，複製內容也帶這三項。
- **權重（D19、D64）**：只有量表項目分權重，預設等重，欄名寫明。除不盡時內部等重、顯示到小數一位。手動改後其他項不動，合計不是 100% 時停用下一步、指出差多少、附「恢復等重」。
- **逐人勾選（D47、D48，R-015）**：`.plist` 每列一位同學，多票可展開逐份勾選，取代原本的處理對話框。整類規則（D49）是預設，逐人是例外，標「N 位為手動調整」。名單顯示投給誰，投影時隱藏。意見調查與報告回饋的資料檢查同一套。
- **班均（D2）**：寫「班均（已計入 6 組／共 8 組）」，沒有總數時只寫已計入；包含自己這組；資料不齊時上方提示「排名可能改變」。輸出文件尚未改。
- **圖表（D59–D61、D62、D63）**：每個統計畫面右上有「圖表」按鈕開勾選清單，每張圖右上有「換圖」「隱藏」，不做儀表板。圖一律附一句用途說明，只列適用的圖。每種統計預設一張：票選長條、量表堆疊橫條、報告回饋對照條、趨勢折線、交叉熱圖。選擇存在設定與範本，不含資料；統計畫面選的圖是輸出的預設。回饋單放哪些圖在輸出設定全班一致勾選，審稿頁可覆寫單一學生（D62）。編輯器的圖表種類用縮圖清單（D63）。
- **回饋單配色（D65）**：單一配色，轉灰階仍有明度階梯，圖旁有標籤；預覽可切「模擬黑白」。「黑白列印模式」列為後續進階。活潑靠鮮明主色、色塊與 SVG 圖示，不用 emoji、不做大幅插圖。輸出文件模擬頁尚未改配色。
- **審稿與評語（13d、D26、D66）**：統一「已完成 N／總人數 人」加細軌道，有寫評語或標「跳過」就算完成。常用評語用分類頁籤加搜尋，籌碼顯示短標題、可預覽整句、插在游標處、支援 {姓名}；內建六類草稿見[常用評語草稿](常用評語草稿.md)，待使用者定稿。「存成常用評語」在評語欄右下角，預設存整段、有選取存選取部分，姓名換成 {姓名}，先放「我的」，重複時提示不新增。
- **自訂版面（D67–D69）**：「版面」指整份範本。頂端列「恢復預設」要二次確認；區塊與頁面設定在各自面板局部還原。第一次修改內建範本就複製成「我的範本」並命名，重複時提示。「已儲存在這個瀏覽器」可點，說明位置並提供備份入口。

### 5.21 並排卡片（共用規則，R-020、R-026）

並排的卡片等高；按鈕貼底、在同一水平線；兩顆按鈕保留主次樣式。兩框並排時（`.twin`）內距、圓角、字級一致，高度隨較長者並設相同最小高度；唯讀用灰底加標籤，可編輯用白底。D25 已套用；D7 改單一入口、D48 改名單後，這兩處不再有並排卡片。

## 6. 文案語氣

- 台灣繁體中文，用「你」不用「您」；短句、直接說做了什麼。
- 按鈕寫動作：「下一步：對應欄位」「產生並下載」「套用」。
- 錯誤說明哪裡錯、怎麼改，不道歉：「讀不到這個檔案。請確認是 xlsx 或 csv。」
- 隱私說明用標準句，各畫面引用同一組：「本程式沒有伺服器，資料只在這個瀏覽器處理，關閉頁面就清除。檔案若放在雲端硬碟或同步資料夾，由該雲端服務處理。」手機版把「這個瀏覽器」寫成「這支手機的瀏覽器」。不要再寫「不會上傳」（R-005）。
- 用詞：一律「試算表」「Excel 檔」，不用「問卷檔」；對使用者說明自動判斷時一律「智慧判斷」，不用「猜」。拖放區不提 csv，但功能仍支援。
- 介面文字集中放在可替換的字串檔，英文 v1.0 補。

## 7. 無障礙

文字對比至少 4.5:1；點擊區至少 44px（預設 48）；所有圖示按鈕有 `aria-label`；狀態不只靠顏色；焦點框清楚可見；單選用 `role="radio"`；進度條用 `role="progressbar"`；支援系統字級放大與 `prefers-reduced-motion`；深色模式兩套都要過對比。

## 8. 不要做的事

- 不載入網路字型、CDN 圖示或任何外部資源（零費用、隱私、離線）。
- 不用彩色當唯一的資訊管道；不用 emoji 當圖示或裝飾。
- 不用漸層、大面積陰影、帶左側色邊的圓角卡片、膠囊形狀態標籤。
- 手機版不用小於 44px 的可點元件，不用 hover 才出現的功能，不用雙擊或長按作為唯一操作（編輯器的長按拖曳必須另有上下按鈕）。
- 不在介面放使用者沒要求的統計或裝飾性數字。
- 不複製 Teacher Hub 的檔案或 token（其授權為非商用，與本專案 GPL-3.0 不同）；只在氣質上讓兩者並列時不衝突。
