## 替代路徑：表單「回覆」分頁的「⋮」選單（有回應後才可用）

「⋮」選單項目（由上至下）：「有新回應時透過電子郵件通知我」「選取回應目標位置」「取消連結表單」「**下載回應 (.csv)**」「列印所有回應」「刪除所有回應」。本次表單沒有回應，所以「下載回應 (.csv)」「列印所有回應」「刪除所有回應」是灰色不可按。（截圖 09）  
**這條路徑匯出的是 csv，不是 xlsx**；教學主推「回應試算表 → 檔案 → 下載 → Microsoft Excel (.xlsx)」，csv 是備案。

## 對現有設計稿的影響（我的建議，待設計員處理）

- 舊設計稿與藍圖常寫「**建立回應試算表**」「匯出」；實際是「**連結至試算表**」→「**建立新試算表**」，匯出是「**檔案 → 下載 → Microsoft Excel (.xlsx)**」。**所有教學、示意圖、錯誤提示的文字要改成上面的原字。**
- 要留意同一畫面「回覆」「回應」並用（分頁「回覆」、計數與對話框「回應」），教學要照實際畫面抄，不要統一用字。
- 第 1 步的 Gemini 視窗要放進示意圖或註解，否則老師會以為畫面不對。
