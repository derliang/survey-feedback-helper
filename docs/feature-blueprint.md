## 一、架構前提

GitHub Pages 只能放靜態網頁，沒有後端。整個程式在老師的瀏覽器內完成，學生資料不上傳。

| 限制 | 影響 | 做法 |
|---|---|---|
| 讀寫本機檔案 | Chrome／Edge 可直接存回原檔；Safari／Firefox 不行 | 支援者用 File System Access API，其餘退回選檔／下載 |
| 存取 Google 雲端硬碟 | 需 Google OAuth 用戶端 ID | v0.4 做，由使用者本人建立 Google Cloud 專案 |
| PDF 輸出（中文） | 內嵌中文字型很大、易跑版 | 用瀏覽器列印轉 PDF，版面以 HTML/CSS 控制 |

## 二、資料進來

- 開啟本機 xlsx／csv；Google 表單匯出格式為主要來源，也可讀雲端回覆試算表（v0.4）。
- 欄位對應精靈：時間戳記、姓名、座號、各題類型（單選、複選、量表、開放題）。
- 學生名單匯入與對照：顯示誰沒填，抓冒名、打錯名字、重複填答。
- 資料檢查：重複、空白、無效票、格式異常，列出讓老師決定處理方式。
- 附示範資料。

## 三、統計

- 基礎：次數、百分比、平均、中位數、標準差、分布圖。
- 反向計分題；自訂量表標籤（如「非常同意」）。
- 交叉分析（例如組別比較）。
- 開放題：分組列出、關鍵詞頻率，完全離線，不使用 AI。

### 三種問卷範本

| 類型 | 重點 |
|---|---|
| 票選幹部 | 各職位得票與排名、同票處理（可重現抽籤，記錄隨機種子）、有效票與廢票、限投一票、候補名單、防弊（同人多票、自投、時間戳異常）、投影唱票模式 |
| 意見調查 | 單選、複選、李克特量表、開放題、交叉分析 |
| 報告回饋 | 以被評學生為單位彙整；評分規準加權；去掉最高最低分；自評對他評落差；小組互評貢獻度；優點與建議留言 |

## 四、輸出

- 預設 xlsx；可選 Word（docx）、PDF。
- 兩層：班級總表、個人回饋單（全班連續分頁 PDF；Word 版可打包 zip）。
- 三種版本：教師版（完整）、學生版（匿名彙整）、家長版（精簡）。
- 檔名規則範本，例如 `{班級}_{座號}_{姓名}_回饋單`。
- 去識別化匯出：姓名換代號。
- 統計方法說明頁：用了哪些設定、哪些資料被排除，結果可重現。

### 個人回饋單

- 老師審稿：留言逐則「採用／隱藏／改寫」，另有老師評語欄。
- 關鍵字提醒：可自訂清單，標出可能傷人的字詞請老師先看；不做智慧判斷。
- 是否顯示他人姓名（預設匿名）、是否顯示原始留言、是否附班級平均對照、版面主題、校名 Logo、頁首頁尾。

## 五、設定

- 三層：全域預設、問卷類型範本、單次覆寫。
- 存於瀏覽器本機，可匯出 JSON、匯入還原；設定檔含版本號，改版時自動轉換舊設定。
- 專案檔：資料來源對應＋欄位對應＋設定，下學期可再開。
- 範本分享：匯出入一組欄位對應與設定。

## 六、產品原則

1. **資料不落地**：原始問卷資料只在記憶體，關頁即清；瀏覽器只存設定。
2. **畫面明講隱私**：「資料只在你的電腦處理」。
3. **統計正確性優先**：計算有自動化測試，票數不能算錯。
4. **操作門檻低**：三步驟流程（匯入 → 確認欄位與類型 → 設定與預覽 → 輸出）。

## 七、介面與設計

- 設計系統由設計員先建立，含兩套視覺：網頁介面、輸出文件（適合列印、給學生看，語氣偏溫暖）。
- 離線可用（PWA）、深色模式、鍵盤操作、手機／平板檢視、圖表另存圖片。
- 隨附「如何設計 Google 表單才好分析」教學頁與範本表單。
- 英文介面為選配。
