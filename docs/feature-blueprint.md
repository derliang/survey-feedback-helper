## 一、產品原則（硬規則）

1. **純網頁、免安裝、免註冊**：GitHub Pages 靜態網站，沒有後端。
2. **全裝置可用**：手機、平板、桌機各自設計版面與操作（mobile-first）。
3. **資料不落地**：原始問卷資料只在記憶體，關頁即清；瀏覽器只存設定、範本與檔案存取代號。
4. **資料不離開瀏覽器**：不上傳學生資料，不蒐集使用數據（連匿名統計也不要）。
5. **全專案零費用**：Google API、字型、CDN、套件、部署皆不得產生費用；Google Cloud 專案不綁帳單帳戶。
6. **main 即上線**：PR 全部通過、使用者說「發布」才合併。
7. **統計正確性優先**：統計核心有自動化測試，票數不能算錯。
8. **畫面與 README 明講隱私**，並提醒依學校個資規範保管輸出檔。

## 二、架構

```
統計結果 + 範本(文件模型 JSON) → 預覽／編輯 → xlsx / Word / PDF
```

- **統計核心**：純函式模組，不依賴瀏覽器，可獨立測試。
- **文件模型與輸出器**：預覽、PDF、Word 共用同一份文件模型。
- **儲存提供者**：本機檔案、下載與上傳、系統分享、Google Drive API，依裝置自動選用。
- 技術選型見 [技術選型與發布規則](decisions/2026-10-30-技術選型與發布規則.md)。

## 三、裝置與瀏覽器

| 裝置 | 版面 | 操作重點 |
|---|---|---|
| 手機（約 360～430px） | 單欄、一次一個步驟、底部操作列與底部彈出面板 | 觸控目標至少 44px，單手可用 |
| 平板（約 768～1024px） | 左右分欄（清單＋預覽），可橫豎切換 | 觸控與手寫筆 |
| 桌機（1280px 以上） | 三欄工作台：資料／預覽／屬性面板 | 鍵盤快速鍵、滑鼠拖曳 |

- 支援近兩年的 Chrome、Edge、Safari、Firefox 與 iOS 16.4 以上；更舊的顯示提示。
- 每個 PR 用 Playwright 在多解析度與觸控模式下測試與檢查跑版。
- 設計系統從手機開始設計，明訂斷點與各裝置元件規格。

## 四、資料進來

- 開啟本機 xlsx／csv；Google 表單匯出格式為主；Google 試算表經軌一轉 xlsx（v0.4）。
- 欄位對應精靈：時間戳記、姓名、座號、各題類型（單選、複選、量表、開放題）。
- 學生名單匯入與對照：誰沒填、冒名、打錯名字、重複填答。
- 資料檢查：重複、空白、無效票、格式異常，列出讓老師決定。
- 附虛構示範資料，入口在教學頁（2026-10-31 修訂）。

## 五、統計

- 基礎：次數、百分比、平均、中位數、標準差、分布圖。
- 反向計分題、量表標籤自訂、交叉分析。
- 開放題：分組列出、關鍵詞頻率，離線，不用 AI。

| 類型 | 重點 |
|---|---|
| 票選幹部 | 各職位得票與排名、同票處理（可重現抽籤、記錄隨機種子）、有效票與廢票、限投一票、候補、防弊（同人多票、自投、時間戳異常）、投影唱票模式 |
| 意見調查 | 單選、複選、李克特量表、開放題、交叉分析 |
| 報告回饋 | 以被評學生為單位彙整；評分規準加權；去掉最高最低分；自評對他評落差；小組互評貢獻度；優點與建議留言 |
| 歷次趨勢 | 同一班多次問卷並排比較 |

## 六、輸出與線上編輯

### 輸出
- 預設 xlsx；另可輸出 Word（docx）與 PDF。
- **PDF 程式直接產生為主**（字型子集化），批次一鍵輸出每位學生各一個 PDF 的 zip；瀏覽器列印僅作桌機備用。
- 兩層：班級總表、個人回饋單。
- 三種版本：教師版（完整）、學生版（匿名彙整）、家長版（精簡）。
- 檔名規則範本，例如 `{班級}_{座號}_{姓名}_回饋單`。
- 去識別化匯出：姓名換代號。
- 統計方法說明頁：用了哪些設定、哪些資料被排除，結果可重現。

### 文件模型與區塊編輯器（層級二＋高自由度）
- 範本由區塊組成：標題、文字、統計表、圖表、留言區、老師評語、頁首頁尾、分隔線、圖片、分頁；文字可用變數（`{姓名}`、`{平均分}`、`{班級平均}`）。
- 編輯能力：直接在預覽上改文字、拖曳排序、增刪區塊、多欄、頁面大小與邊界、背景與頁框、圖片與 Logo、圖表顏色、條件顯示、單一學生個別覆寫。
- **手機也有完整編輯器**，以觸控專用設計實現：長按把手拖曳＋上下按鈕、底部彈出屬性面板、預覽縮放、編輯與捲動模式分開、復原／重做。
- Word 不支援的效果在編輯器中標示。
- 範本存本機，隨設定匯出／還原，可分享。

### 個人回饋單
- 老師審稿：留言逐則「採用／隱藏／改寫」，加老師評語欄。
- 關鍵字提醒：可自訂清單，不做智慧判斷。
- 是否顯示他人姓名（預設匿名）、顯示原始留言、附班級平均對照、版面主題、校名 Logo、頁首頁尾。

## 七、設定

- 三層：全域預設、問卷類型範本、單次覆寫。
- 存於瀏覽器本機，可匯出 JSON、匯入還原；設定檔含版本號，改版自動轉換。
- 專案檔：資料來源對應＋欄位對應＋設定，下學期可再開。

## 八、Google 雲端硬碟雙軌

> 2026-10-31 修訂：軌二不再是獨立入口，併入「本機檔案」；軌一入口在設定頁。見[決定記錄](decisions/2026-10-31-頁面討論裁示.md)。

| | 軌一：使用者登入（v0.4） | 軌二：原生檔案管理（併入 v0.1） |
|---|---|---|
| 做法 | Google 登入＋Drive API＋Picker | 裝置檔案／資料夾選擇器 |
| 桌機 | 所有瀏覽器 | Chrome／Edge 選「Google 雲端硬碟 for desktop」資料夾，直接讀寫並同步 |
| 手機／平板 | 可用 | 系統選檔視窗本來就列出 Drive |

- 只申請 `drive.file` 權限；Google Cloud 專案不綁帳單帳戶；API 金鑰限 Pages 網址、只開 Drive 與 Picker。
- Drive for desktop 內的 Google 原生格式只是捷徑，不能直接當 xlsx 讀；軌一可自動轉換。
- 配額用完只會被拒絕、不會收費；介面顯示友善提示並建議改用軌二。
