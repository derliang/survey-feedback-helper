# 問卷回饋小幫手 (Survey Feedback Helper)

給老師用的網頁工具：開啟 Google 表單匯出的問卷結果，自動統計，並產出精美的班級總表與學生個人回饋單。手機、平板、桌機的瀏覽器都能用，免安裝。

> **狀態：規劃階段（尚未發布任何版本）。** 目前 repo 只有規劃文件，程式從 v0.1 開始。進度見 [todo.md](todo.md)，版本記錄見 [CHANGELOG.md](CHANGELOG.md)。

## 隱私與資料

- **你的資料只在你的瀏覽器裡處理。** 網頁部署在 GitHub Pages，沒有後端，不會上傳任何學生資料，也不蒐集任何使用數據。
- **原始問卷資料不落地。** 只在記憶體處理，關閉頁面即清除；瀏覽器只儲存設定與範本。
- 輸出的 xlsx、Word、PDF 內含學生資料，請依貴校個人資料保護規範妥善保管。

## 核心原則

- 純網頁、免安裝、免註冊。
- 手機、平板、桌機各自設計版面與操作。
- 全專案零費用：Google API、套件、部署都不產生費用。
- 設定可攜：存在本機，可匯出成 JSON，也可匯入還原。

## 預計功能

| 類別 | 內容 |
|---|---|
| 讀取 | 開啟本機 xlsx／csv、Google 雲端硬碟檔案；欄位對應精靈；資料檢查；學生名單對照 |
| 統計 | 次數、百分比、平均、中位數、標準差、圖表；反向題與量表自訂；交叉分析；開放題分組與關鍵詞 |
| 問卷類型 | 票選幹部（同票抽籤、防弊、投影唱票）、意見調查、報告回饋（加權、去極端值、自評對他評、小組互評） |
| 輸出 | 預設 xlsx；Word；PDF（程式直接產生，可批次輸出每位學生一份）；教師版／學生版／家長版；檔名規則；去識別化匯出；統計方法說明頁 |
| 線上編輯 | 區塊編輯器：直接改文字、拖曳排序、增刪區塊、多欄、頁面與背景、圖片、變數、條件顯示、單一學生覆寫；手機也可完整編輯 |
| 個人回饋單 | 老師審稿（採用／隱藏／改寫）、老師評語、關鍵字提醒、精美版面 |
| 設定 | 全域預設、問卷類型範本、單次覆寫；匯出與還原；專案檔 |
| 其他 | 歷次趨勢比較、離線可用（PWA）、深色模式、Google 表單設計教學與範本 |

完整藍圖見 [docs/feature-blueprint.md](docs/feature-blueprint.md)。

## 技術

TypeScript + Vite + Preact；ExcelJS、docx、fflate；PDF 由程式直接產生；GitHub Actions 部署到 GitHub Pages。選型原因與被否決的方案見 [docs/decisions/](docs/decisions/)。

## 發布規則

本專案 **`main` 即上線**：合併到 `main` 就會發布到 GitHub Pages 正式站。因此每個 PR 都必須通過全部測試與檢查，並經維護者確認後才能合併。參與方式見 [CONTRIBUTING.md](CONTRIBUTING.md)，安全問題回報見 [SECURITY.md](SECURITY.md)。
