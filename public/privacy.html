隱私權政策

最後更新：2026-11-01（台北時間）。適用於「問卷回饋小幫手」網頁程式（https://derliang.github.io/survey-feedback-helper/）。English version below.

重點

  • 本程式沒有伺服器，也不蒐集任何使用數據（連匿名統計都沒有）。
  • 你的問卷結果與學生名單，只在你自己的電腦或手機的瀏覽器裡處理，不會傳給我們。
  • Google 登入是選用的；不登入，改用 Excel 檔也能完整使用。
  • 選用的「自動存到雲端硬碟」預設關閉，打開前會說明並請你確認。

1. 這是什麼

問卷回饋小幫手是免費、開放原始碼（GPL-3.0）的純網頁工具，幫老師整理問卷結果、做統計與輸出回饋文件。原始碼公開在 github.com/derliang/survey-feedback-helper，內容是否與本政策一致，任何人都可以檢查。

2. 我們不蒐集什麼

  • 沒有伺服器、沒有資料庫、沒有帳號系統，所以我們收不到你的任何資料。
  • 沒有分析工具、沒有廣告、沒有追蹤用的 Cookie，也不會把你的使用情形回報給任何人。
  • 介面字型使用你裝置內建的字型；輸出文件用的字型由本站自己提供，不向第三方載入。

3. 你的資料放在哪裡

  • 問卷結果（你開啟的 Excel 檔或 Google 試算表內容）：只在這個瀏覽器的記憶體裡計算，關掉分頁就沒了；不會寫進瀏覽器的儲存空間。
  • 設定檔、學生名單、審稿進度：存在你自己選的電腦資料夾（桌機 Chrome、Edge）。沒有資料夾的裝置（手機、平板、Safari、Firefox），由你手動下載或「儲存到檔案」。
  • 瀏覽器只記得：資料夾的存取代號，以及介面偏好（語言、外觀、是否開啟雲端自動備份）。不含問卷作答與名單內容；被清掉時，程式會請你重新選一次資料夾。
  • 輸出的檔案（個人回饋單、報告等）由你下載，之後怎麼保管、分享，由你決定。
  • 為了離線可用，程式會把程式本身（網頁、字型）快取在瀏覽器，不快取任何問卷資料。

4. Google 登入（選用）

只有在你要「開啟 Google 試算表」，或打開「自動存到雲端硬碟」時，才會請你登入 Google。

  • 只申請一個權限：drive.file。這個權限只讓本程式存取「你用 Google 的檔案選擇器選的檔案」與「本程式自己建立的設定檔」；看不到你雲端硬碟裡的其他檔案，也不會要求讀取你的信箱、聯絡人或行事曆。授權畫面上的實際字樣 待核對
  • 讀取試算表：你選的那份試算表的內容，由你的瀏覽器直接向 Google 讀取，只在瀏覽器裡處理，不會經過我們（我們沒有伺服器）。
  • 登入憑證（權杖）只放在瀏覽器的記憶體，不寫進任何儲存空間；重新整理或關掉分頁就消失，下次要再登入一次。
  • 登入時，瀏覽器會從 Google（accounts.google.com）載入 Google 提供的登入程式，Google 依它自己的政策處理你的登入。
  • 本程式對從 Google API 取得的資訊的使用與轉移，會遵守 Google API 服務使用者資料政策（Google API Services User Data Policy），包括其中的「限制使用」（Limited Use）規定：只用來提供你看得到的功能，不用於廣告、不出售、不供人閱讀，也不用來訓練任何模型。

5. 雲端自動備份（選用，預設關閉）

  • 打開前，程式會先說明並請你明確確認；沒有打開，就不會把任何東西存到雲端。
  • 打開後，每次設定有更新，程式會把「問卷小幫手設定.sfh」這一個檔多存一份到你自己的 Google 雲端硬碟（同名覆蓋）。檔案裡有設定、範本與你匯入的學生名單；不含問卷作答結果。
  • 這個檔放在你的帳號底下，我們看不到。如果你登入的是學校帳號，學校管理員可能看得到；名單要保密時，可不要開啟。
  • 只往雲端寫，不會從雲端讀回來蓋掉你電腦上的檔案。
  • 關閉後不再存新的更新；雲端裡已存的那份會留著，本程式不會刪，要刪請自己到 Google 雲端硬碟刪除。

6. 分享給第三方

我們沒有你的資料，所以沒有東西可以出售、出租或分享，也不會揭露給任何第三方。資料會往來的對象只有你自己選擇使用的 Google（第 4、5 節）。另外，本網站放在 GitHub Pages；你開啟網頁時，GitHub 作為主機，可能依 GitHub 的隱私聲明記錄一般連線資訊（例如 IP 位址），本專案取不到這些紀錄。

7. 怎麼撤銷與刪除

  • 停止雲端備份：在程式「設定」關閉「自動存到雲端硬碟」，並可選擇同時中斷 Google 連線。
  • 撤銷 Google 授權：到你的 Google 帳戶，在「安全性」裡找「第三方應用程式和服務的存取權」（實際名稱 待核對），選「問卷回饋小幫手」後移除存取權。
  • 刪除雲端那一份：到你的 Google 雲端硬碟，自己刪除「問卷小幫手設定.sfh」。
  • 刪除這台裝置上的記錄：在程式「設定」按「忘記這個資料夾」（只讓瀏覽器忘記位置，不動資料夾裡的檔案），或清除瀏覽器對本網站的資料。

8. 學生資料

問卷與名單裡的學生資料屬於老師與學校。本程式不蒐集、不上傳；但輸出的檔案與你存的設定檔（含名單）會出現學生姓名，請依學校的規定保管。我們的原始碼公開，因此永遠不會把學生資料放進公開的專案。

9. 本政策的修改

內容變更時，會更新本頁開頭的日期；歷次修改都可以在 GitHub 的版本紀錄查到。

10. 聯絡方式

有疑問或想回報問題，請到 GitHub Issues 留言。Issues 是公開的，請不要貼學生資料或任何個人資料。

Privacy Policy (English)

Last updated: 2026-11-01 (Taipei time). Applies to the web app “Survey Feedback Helper” (問卷回饋小幫手) at https://derliang.github.io/survey-feedback-helper/. The Traditional Chinese text above is the original; this is a faithful summary.

Summary

  • There is no server, and the app collects no usage data (not even anonymous statistics).
  • Survey results and student rosters are processed only in your own browser. They are never sent to us.
  • Google sign-in is optional. You can use an Excel file instead.
  • The optional “save to Google Drive” backup is off by default and asks for your explicit confirmation first.

What we do not collect

No server, database or account system, so we cannot receive your data. No analytics, no ads, no tracking cookies. Fonts for exported documents are served from this site itself, not from third parties.

Where your data lives

  • Survey results (your Excel file or Google Sheet) are processed in browser memory only and are not written to browser storage.
  • Settings, rosters and review progress are saved in a folder on your computer that you choose (desktop Chrome or Edge), or downloaded by you on other devices.
  • The browser only remembers a folder access handle and interface preferences (language, appearance, whether cloud backup is on). It does not remember survey answers or roster contents.
  • For offline use, the app caches its own code and fonts, never survey data.

Google sign-in (optional)

  • The app requests a single scope, drive.file. It lets the app access only files you pick with Google’s file picker and the settings file the app itself creates. It cannot see other files in your Drive, and it does not ask for your email, contacts or calendar. The exact wording on Google’s consent screen is still to be checked.
  • The spreadsheet you choose is read directly from Google by your browser and processed there. It does not pass through us, because we have no server.
  • The sign-in token is kept in browser memory only. It disappears when you reload or close the tab.
  • When you sign in, your browser loads Google’s sign-in script from accounts.google.com; Google handles your sign-in under its own policies.
  • The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements: data is used only to provide the user-facing features, and is not used for advertising, sold, read by humans, or used to train models.

Optional cloud backup (off by default)

If you turn it on, each time your settings change the app saves one file, “問卷小幫手設定.sfh”, to your own Google Drive (overwriting the previous copy). The file contains settings, templates and the student roster you imported, but not survey answers. We cannot see it. If you sign in with a school account, your school’s administrator may be able to see it. Turning the option off stops further saving; the copy already in your Drive stays until you delete it yourself. The app only writes to Drive and never reads it back over your local files.

Sharing

We hold no data, so we have nothing to sell, rent or share. Data only goes to Google, if you choose to use it. This site is hosted on GitHub Pages; GitHub, as the host, may log ordinary connection information (such as IP addresses) under its own privacy statement, and this project has no access to those logs.

Revoking access and deleting data

  • Turn off “save to Google Drive” in the app’s Settings; you may also disconnect Google there.
  • Remove the app’s access in your Google Account, under Security, “third-party apps and services” (exact name to be checked).
  • Delete “問卷小幫手設定.sfh” from your Google Drive yourself.
  • Use “Forget this folder” in Settings, or clear this site’s data in your browser.

Student data

Student data belongs to teachers and schools. The app does not collect or upload it, but exported files and the saved settings file (which includes the roster) contain student names; please store them according to your school’s rules. This project never puts student data into its public repository.

Changes and contact

When this policy changes, the date at the top is updated, and the history is available in the GitHub repository. For questions, please open an issue at GitHub Issues. Issues are public, so do not post student or personal data there.
